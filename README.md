# 思齐个人主页

🎓 控制工程研究生的个人博客

## ✨ 功能特点

- 📚 **课程管理**：课程资料、PPT、视频、学习进度
- 📝 **论文追踪**：论文状态、分类标签（阅读/撰写/中文/英文/查重/投稿）
- 🔔 **学校通知**：重要公告与通知
- 👥 **班级事务**：班级通知、作业、活动
- ☁️ **生活服务**：常用网站快速入口
- 💰 **生活记账**：收支记录与统计
- 📖 **日记**：记录生活点滴
- 🎓 **导师指导**：与导师交流记录
- 🔍 **全站搜索**：快速找到所有内容
- 📝 **关于我**：个人介绍
