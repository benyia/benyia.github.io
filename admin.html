GitHub 文件上传设置

要在课程/论文里上传文件并让所有访客都能下载，需要设置一个 GitHub Token：

生成方式：GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
勾选 repo 权限即可。Token 只保存在你浏览器里，不会上传到服务器。
