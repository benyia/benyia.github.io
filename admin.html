🔑 GitHub 上传设置（必读）

保存和上传文件需要通过 GitHub Token 验证身份。Token 只保存在你自己的浏览器里，不会写进网页，也不会出现在公开仓库中。
获取方式：GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)，勾选 repo 权限，生成后粘贴到下面。
