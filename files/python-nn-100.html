    开课前数学自查

    下面五条不要求全部会推，但至少要能看懂符号。看不懂就先补对应部分，再回到第三章，不要硬背公式。

    1. 矩阵乘法：$(m \times n)\cdot(n \times p)\to(m \times p)$，内维必须相等；偏置相加依赖广播。
    2. 导数与链式法则：$\dfrac{dz}{dx}=\dfrac{dz}{dy}\cdot\dfrac{dy}{dx}$，反向传播就是把它一层层乘回去。
    3. 常见激活函数导数：sigmoid 的导数是 $\sigma(1-\sigma)$，ReLU 在正区间导数为 1、负区间为 0。
    4. softmax + 交叉熵：对 logits 的梯度可以化简为 $p-\operatorname{onehot}(y)$，这是分类网络最常用的一组公式。
    5. 梯度下降：$\theta \leftarrow \theta-\mathrm{lr}\cdot\dfrac{\partial L}{\partial \theta}$；学习率太大发散，太小收敛慢。

    附录 A · 形状与梯度速查

    神经网络代码里 80% 的 bug 来自形状对不上或在错误的位置求了梯度。先把下面四组关系记牢，再去看任何模型代码都会轻松很多。

    $$ \begin{aligned} X &\in \mathbb{R}^{B\times d_{\mathrm{in}}}, \qquad W \in \mathbb{R}^{d_{\mathrm{in}}\times d_{\mathrm{out}}} \\ \mathrm{logits} &= XW + b \in \mathbb{R}^{B\times d_{\mathrm{out}}} \\ \mathcal{L} &= \operatorname{CrossEntropy}(\mathrm{logits}, y) \\ \frac{\partial \mathcal{L}}{\partial \,\mathrm{logits}} &= \operatorname{softmax}(\mathrm{logits})-\operatorname{onehot}(y) \end{aligned} $$
    • 矩阵乘法：$(m \times n)\cdot(n \times p)\to(m \times p)$。中间的 $n$ 必须相等；转置 $W^{\mathsf{T}}$ 常用于把 $(\mathrm{out},\mathrm{in})$ 变成 $(\mathrm{in},\mathrm{out})$。
    • 广播：$(\mathrm{batch},\mathrm{features})+(\mathrm{features},)$ 会把偏置复制到每个样本；$(\mathrm{batch},1)$ 与 $(1,\mathrm{out})$ 相加会得到 $(\mathrm{batch},\mathrm{out})$。
    • 链式法则：$\dfrac{\partial L}{\partial W_1}=\dfrac{\partial L}{\partial H}\cdot\dfrac{\partial H}{\partial Z_1}\cdot\dfrac{\partial Z_1}{\partial W_1}$。反向传播不是新公式，只是从后往前反复用链式法则。
    • 常用导数：sigmoid $\sigma'(z)=\sigma(z)\bigl(1-\sigma(z)\bigr)$；tanh $1-\tanh^2(z)$；ReLU 正区间为 1、负区间为 0；MSE 对预测值的导数是 $2(\hat{y}-y)/n$。
    • softmax + 交叉熵：把 logits 变成概率 $p_i=\dfrac{e^{z_i}}{\sum_j e^{z_j}}$，损失 $L=-\log p_y$，对 logits 的梯度直接化简为 $p-\operatorname{onehot}(y)$。这也是 PyTorch 里 CrossEntropyLoss 自带 softmax 的原因——不要再手动加一层 softmax。
    • 梯度下降：$\theta\leftarrow\theta-\mathrm{lr}\cdot\dfrac{\partial L}{\partial\theta}$。所有优化器（SGD、Adam、AdamW）都是在决定“这一步往哪走、走多远”。

    附录 B · 手算一次反向传播

    用一个最小的 2–2–1 网络把数字走一遍。输入 $x=[1.0,\,0.5]$，目标 $y=1$，隐藏层用 sigmoid，输出层用 sigmoid，损失用 $L=\tfrac{1}{2}(\hat{y}-y)^2$。先别看答案，拿纸跟着算一遍，比读十遍公式有用。

    初始权重与一次前向传播
    步骤计算结果
    隐藏层输入$z_1=W_1x+b_1$，$W_1=\begin{bmatrix}0.2&0.4\\0.1&-0.3\end{bmatrix}$，$b_1=[0,\,0.1]$$z_1=[0.4,\,0.05]$
    隐藏层输出$h=\sigma(z_1)$$h=[0.59869,\,0.51250]$
    输出层输入$z_2=W_2h+b_2$，$W_2=[0.3,\,-0.2]$，$b_2=0$$z_2=0.07711$
    预测值$\hat{y}=\sigma(z_2)$$\hat{y}=0.51927$
    损失$L=\tfrac{1}{2}(\hat{y}-1)^2$$L=0.11555$
    反向传播：从输出层往输入层算
    步骤计算结果
    输出层误差$\delta_2=(\hat{y}-y)\,\hat{y}(1-\hat{y})$$\delta_2=-0.12002$
    W2 梯度$\dfrac{\partial L}{\partial W_2}=\delta_2 h^{\mathsf{T}}$$[-0.07186,\,-0.06151]$
    b2 梯度$\dfrac{\partial L}{\partial b_2}=\delta_2$$-0.12002$
    隐藏层误差$\delta_1=\bigl(W_2^{\mathsf{T}}\delta_2\bigr)\odot h(1-h)$$[-0.00865,\,0.00600]$
    W1 梯度$\dfrac{\partial L}{\partial W_1}=\delta_1 x^{\mathsf{T}}$$\begin{bmatrix}-0.00865&-0.00433\\0.00600&0.00300\end{bmatrix}$
    更新（$\mathrm{lr}=0.5$）$W\leftarrow W-\mathrm{lr}\,\dfrac{\partial L}{\partial W}$$W_2\approx[0.3359,\,-0.1692]$，$W_1$ 同步更新
    更新后损失重新前向一次$L\approx0.1110$（下降了）
    检查点：如果你算出的 δ2 符号反了，通常是损失写成 ŷ-y 还是 y-ŷ 的约定不同；只要前后一致，梯度方向就不会错。真正要保证的是：更新后损失必须下降，否则学习率或符号有问题。

    附录 C · PyTorch 最小训练模板

    下面这份代码把“数据 → 模型 → 损失 → 训练 → 验证 → 早停 → 保存”串成了一条完整链路。把 X 和 y 换成你的数据，再把第一层输入维度改掉，就能直接跑。注意三个固定动作：optimizer.zero_grad()、loss.backward()、optimizer.step()。

    import random
import numpy as np
import torch
from torch import nn
from torch.utils.data import TensorDataset, DataLoader

SEED = 42
random.seed(SEED)
np.random.seed(SEED)
torch.manual_seed(SEED)

# 1. 数据：这里用合成二分类数据，换成你的 X / y 即可
X = torch.randn(1000, 20)
w_true = torch.randn(20, 1)
y = (X @ w_true + 0.1 * torch.randn(1000, 1) > 0).long().squeeze(1)

ds = TensorDataset(X, y)
train_ds, val_ds = torch.utils.data.random_split(
    ds, [800, 200], generator=torch.Generator().manual_seed(SEED)
)
train_loader = DataLoader(train_ds, batch_size=64, shuffle=True)
val_loader = DataLoader(val_ds, batch_size=256)

# 2. 模型：输入 20 维，隐藏层 64，输出 2 类
model = nn.Sequential(
    nn.Linear(20, 64),
    nn.ReLU(),
    nn.Linear(64, 2),
)

# 3. 损失与优化器：分类用 CrossEntropyLoss，内部自带 softmax
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)

def evaluate():
    model.eval()
    correct = total = 0
    loss_sum = 0.0
    with torch.no_grad():
        for xb, yb in val_loader:
            logits = model(xb)
            loss_sum += criterion(logits, yb).item() * len(yb)
            correct += (logits.argmax(1) == yb).sum().item()
            total += len(yb)
    return loss_sum / total, correct / total

# 4. 训练：早停 + 保存验证集最优权重
best_loss, best_state, patience, wait = float("inf"), None, 5, 0
for epoch in range(50):
    model.train()
    for xb, yb in train_loader:
        optimizer.zero_grad()
        loss = criterion(model(xb), yb)
        loss.backward()
        optimizer.step()

    val_loss, val_acc = evaluate()
    if val_loss < best_loss:
        best_loss = val_loss
        best_state = {k: v.clone() for k, v in model.state_dict().items()}
        wait = 0
    else:
        wait += 1
        if wait >= patience:
            print(f"早停于 epoch {epoch + 1}")
            break
    print(f"epoch {epoch + 1:02d} | val_loss {val_loss:.4f} | val_acc {val_acc:.2%}")

# 5. 保存与恢复：只保存权重，加载时先建同结构模型
if best_state:
    model.load_state_dict(best_state)
torch.save({"model": model.state_dict(), "seed": SEED}, "checkpoint.pt")

loaded = nn.Sequential(nn.Linear(20, 64), nn.ReLU(), nn.Linear(64, 2))
loaded.load_state_dict(torch.load("checkpoint.pt", weights_only=True)["model"])
loaded.eval()

    附录 D · 常见报错速查

    看到红字先定位错误类型，再对照处理
    报错常见原因处理
    ModuleNotFoundError: No module named 'torch'没装库，或装了但当前解释器不是同一个环境pip install torch；在 VS Code 右下角切换正确的 Python 解释器
    RuntimeError: mat1 and mat2 shapes cannot be multiplied矩阵内维不匹配打印两边的 .shape；检查是否需要转置或改 in_features
    RuntimeError: Expected all tensors to be on the same device模型在 GPU，数据在 CPU（或反过来）统一执行 x = x.to(device)、model.to(device)
    RuntimeError: element 0 of tensors does not require grad对不需要梯度的张量调了 backward()检查 requires_grad=True，或不要对验证集损失反向传播
    RuntimeError: Trying to backward through the graph a second time同一个计算图被反向了两次每次迭代重新前向；确实需要时用 retain_graph=True，或对旧张量 detach()
    ValueError: Target size ... must be the same as input sizeCrossEntropyLoss 的输入是 (N,C)，标签却传成了 (N,1) 或 one-hot标签用 long() 且形状为 (N,)；不要在分类标签上做 one-hot
    CUDA out of memory显存不够减小 batch_size、图像尺寸；用 torch.cuda.empty_cache() 只能缓解，不能根治
    IndexError: index out of range / KeyError下标越界、字典键不存在检查 len() 与键名；字典用 get(key, default)
    IndentationError / SyntaxError缩进不一致、少了冒号或括号统一用 4 个空格；看报错指出的行号上一行
    NameError: name 'np' is not defined忘了 import numpy as np，或作用域不对在文件顶部补 import；函数内部不要依赖未传入的全局变量
    OSError: [Errno 22] Invalid argumentWindows 路径含非法字符，或文件被占用用 pathlib.Path 拼接路径；关闭正在占用文件的程序
    训练 loss 不下降 / 变成 nan学习率过大、数据未归一化、log(0)先把 lr 降到 1e-3 或 1e-4；标准化输入；给 log 加 1e-8

    附录 E · 术语表

    张量（Tensor）
    带形状和数据类型的高维数组；PyTorch 的张量还支持自动求导和 GPU 计算。
    形状（shape）
    每一维的长度，例如 (32, 784) 表示 32 个样本、每个 784 个特征。
    广播（broadcasting）
    形状不同的数组按规则自动扩展后再逐元素运算，常用于加偏置。
    前向传播（forward）
    输入经过各层计算得到预测值的过程。
    反向传播（backpropagation）
    从损失出发，用链式法则逐层计算参数梯度的过程。
    梯度（gradient）
    损失对某个参数的偏导数，指示“参数往哪个方向调会让损失下降”。
    学习率（learning rate）
    每次更新参数的步长；太大震荡，太小收敛慢。
    epoch / batch / step
    epoch 是完整遍历一次训练集；batch 是一次送入模型的样本数；step 是一次参数更新。
    过拟合（overfitting）
    训练集表现好、验证集表现差，模型记住了噪声而非规律。
    正则化（regularization）
    抑制过拟合的手段，如权重衰减、Dropout、数据增强、早停。
    激活函数（activation）
    给网络引入非线性的函数，常见有 ReLU、sigmoid、tanh、GELU。
    logits
    softmax 之前的原始分数，可正可负，不要求和为 1。
    交叉熵（cross-entropy）
    分类任务常用损失，衡量预测分布与真实分布的差异。
    优化器（optimizer）
    根据梯度更新参数的算法，如 SGD、Adam、AdamW。
    autograd
    PyTorch 的自动求导引擎，会记录张量运算并自动计算梯度。
    checkpoint
    保存下来的模型权重（有时还包括优化器状态），用于恢复训练或推理。

    • 图像分类迁移学习：用预训练 ResNet 微调一个自己的小数据集，比较“冻结骨干”和“全量微调”的差异。
    • 文本情感分类：Embedding + GRU 或小型 Transformer，要求处理 padding、mask 和类别不均衡。
    • 回归任务：预测房价或温度，练习特征标准化、MSE/MAE 对比和残差分析。
    • 复现一篇小论文：选一篇有官方代码的短文，固定随机种子跑通，再尝试改一个模块并报告结果。
    写论文式总结：每个项目至少留下四样东西——数据说明、实验配置、对比表格、失败案例分析。能把“为什么没work”讲清楚，比只报一个最高分更有说服力。
