一、（15分）离散控制系统如下图所示，其中 $D(z)=1$，采样周期 $T=0.5\text{s}$，零阶保持器 $W_{h0}(s)=\dfrac{1-e^{-sT}}{s}$，被控对象 $W(s)=\dfrac{K}{s+2}$。（计算结果保留 4 位小数）

试：

（1）求系统的闭环脉冲传递函数 $W_B(z)$（用 $K$ 表示）；（4分）

（2）判断闭环系统的稳定性，确定使闭环系统稳定的增益 $K$ 的取值范围；（3分）

（3）当 $K=3$ 时，若输入为单位阶跃信号，求系统输出 $y(t)$ 前三个采样周期时刻的值 $y(0)$、$y(1)$、$y(2)$ 及通项表达式 $y(k)$；（5分）

（4）当 $K=3$ 时，求系统在单位阶跃信号输入时的稳态误差 $e(\infty)$。（3分）

解：

（1）求系统开环与闭环脉冲传递函数：

系统开环脉冲传递函数为（已知 $T=0.5\text{s}$，$e^{-2T}=e^{-1}\approx 0.3679$）： $$W_d(z) = \mathcal{Z}[W_{h0}(s)W(s)] = \mathcal{Z}\left(\frac{1-e^{-sT}}{s}\cdot\frac{K}{s+2}\right) = \frac{K}{2}(1-z^{-1})\left[\frac{1}{1-z^{-1}} - \frac{1}{1-e^{-2T}z^{-1}}\right]$$ $$= \frac{K}{2}\times\frac{1-e^{-2T}}{z-e^{-2T}} = \frac{K}{2}\times\frac{1-0.3679}{z-0.3679} = \frac{0.3161K}{z-0.3679}$$
2分
系统闭环脉冲传递函数为： $$W_B(z) = \frac{D(z)W_d(z)}{1+D(z)W_d(z)} = \frac{\dfrac{0.3161K}{z-0.3679}}{1+\dfrac{0.3161K}{z-0.3679}} = \frac{0.3161K}{z - 0.3679 + 0.3161K}$$
2分

（2）判断闭环系统的稳定性：

系统的特征方程为 $z - 0.3679 + 0.3161K = 0$，特征根为 $z = 0.3679 - 0.3161K$。
当 $|z| = |0.3679 - 0.3161K| < 1$，即 $-1.9997 < K < 4.3274$ 时，闭环系统稳定。
3分

（3）当 $K=3$ 时，求 $y(0)$、$y(1)$、$y(2)$ 及 $y(k)$：

当 $K=3$ 时，$0.3161\times 3 = 0.9482$（精确值 $1.5\times 0.6321 = 0.9482$），闭环传递函数为： $$W_B(z) = \frac{0.9482}{z + 0.5803}$$ 输入为单位阶跃信号 $R(z)=\dfrac{z}{z-1}$ 时，利用长除法得： $$Y(z) = W_B(z)R(z) = \frac{0.9482}{z+0.5803}\cdot\frac{z}{z-1} = \frac{0.9482z}{z^2 - 0.4197z - 0.5803}$$ $$= 0z^0 + 0.9482z^{-1} + 0.3980z^{-2} + 0.7172z^{-3} + \cdots$$ 故：$y(0)=0$，$y(1)=0.9482$，$y(2)=0.3980$。
2分
由部分分式展开法求通项 $y(k)$： $$\frac{Y(z)}{z} = \frac{0.9482}{(z-1)(z+0.5803)} = \frac{0.9482}{1.5803}\left[\frac{1}{z-1} - \frac{1}{z+0.5803}\right] = 0.6000\left[\frac{1}{z-1} - \frac{1}{z+0.5803}\right]$$ $$Y(z) = 0.6000\left[\frac{z}{z-1} - \frac{z}{z+0.5803}\right] \implies y(k) = 0.6000\left[1 - (-0.5803)^k\right]$$
3分

（4）求 $K=3$ 时单位阶跃输入下的稳态误差 $e(\infty)$：

闭环系统极点 $z = -0.5803$，$|z| = 0.5803 < 1$，系统稳定，因此由终值定理得： $$E(z) = R(z)[1 - W_B(z)] = \frac{z}{z-1}\cdot\frac{z-0.3679}{z+0.5803}$$ $$e(\infty) = \lim_{z\to 1}(z-1)E(z) = \lim_{z\to 1}(z-1)\cdot\frac{z}{z-1}\cdot\frac{z-0.3679}{z+0.5803} = \frac{0.6321}{1.5803} = 0.4000 = \frac{2}{5}$$ （或由 $y(\infty) = 0.6000$，得 $e(\infty) = 1 - y(\infty) = 1 - 0.6000 = 0.4000$）。
3分
二、（15分）数字 PID 控制器设计与稳态性能分析（综合 2024、2025 真题第二题）。

设图一所示离散控制系统中，采样周期 $T=1\text{s}$，零阶保持器 $W_{h0}(s)=\dfrac{1-e^{-sT}}{s}$，被控对象 $W(s)=\dfrac{1}{s+1}$，广义被控对象脉冲传递函数已求得为 $W_d(z)=\dfrac{0.6321}{z-0.3679}$。

（1）当数字控制器采用比例控制 $D(z)=K_p$ 时，分析 $K_p$ 的变化对闭环系统稳定性及单位阶跃稳态误差的影响；（4分）

（2）当数字控制器采用比例积分（PI）控制 $D(z) = K_p + K_i\dfrac{1}{1-z^{-1}}$ 时，推导并分析 $D(z)$ 对系统单位阶跃稳态性能的影响；（4分）

（3）若工程中采用模拟 PID 控制器校正：$D(s) = 4\left(1 + \dfrac{1}{2s} + 0.5s\right)$，采样周期 $T=1\text{s}$。试写出其对应的位置式与增量式数字 PID 控制算法；若系统初始时刻 $k=0$，初始输出 $u(0)=0$，采样误差依次为 $e(0)=1$、$e(1)=0.5$、$e(2)=0.2$（当 $k<0$ 时 $e(k)=0$），求控制器输出 $u(1)$、$u(2)$。（7分）

解：

（1）当 $D(z)=K_p$ 时，分析 $K_p$ 变化对系统性能的影响：

系统闭环脉冲传递函数为： $$W_B(z) = \frac{D(z)W_d(z)}{1+D(z)W_d(z)} = \frac{0.6321K_p}{z - 0.3679 + 0.6321K_p}$$ 特征方程为 $z - 0.3679 + 0.6321K_p = 0$，由 $|z| = |0.3679 - 0.6321K_p| < 1$，得稳定范围为 $-1 < K_p < 2.1641$。
2分
在稳定范围内，单位阶跃输入下的稳态误差为： $$e(\infty) = \lim_{z\to 1}(z-1)\frac{z}{z-1}\left[1 - \frac{0.6321K_p}{z - 0.3679 + 0.6321K_p}\right] = \frac{0.6321}{0.6321 + 0.6321K_p} = \frac{1}{1+K_p}$$ 由此可见：在闭环稳定范围内，当 $K_p$ 增大时，系统的稳态误差减小，但 $K_p$ 过大会导致系统失稳。
2分

（2）当 $D(z) = K_p + K_i\dfrac{1}{1-z^{-1}}$ 时，分析对稳态性能的影响：

系统闭环传递函数为： $$W_B(z) = \frac{\left(K_p + K_i\dfrac{1}{1-z^{-1}}\right)\dfrac{0.6321}{z-0.3679}}{1 + \left(K_p + K_i\dfrac{1}{1-z^{-1}}\right)\dfrac{0.6321}{z-0.3679}}$$ 当闭环系统稳定时，单位阶跃输入下的误差脉冲传递函数及稳态误差为： $$E(z) = R(z)[1 - W_B(z)] = \frac{z}{z-1}\cdot\frac{1}{1 + \left(K_p + K_i\dfrac{1}{1-z^{-1}}\right)\dfrac{0.6321}{z-0.3679}}$$ $$e(\infty) = \lim_{z\to 1}(z-1)E(z) = \lim_{z\to 1}\frac{z}{1 + \left(K_p + K_i\dfrac{z}{z-1}\right)\dfrac{0.6321}{z-0.3679}} = 0$$ 由此可见：引入积分控制后，系统的稳态误差为零，积分控制器的作用是消除了系统稳态误差，提高了控制精度。
4分

（3）模拟 PID 离散化及计算 $u(1)$、$u(2)$：

对 $D(s) = \dfrac{U(s)}{E(s)} = 4\left(1 + \dfrac{1}{2s} + 0.5s\right)$ 取拉氏反变换得时域形式： $$u(t) = 4e(t) + 2\int_0^t e(t)\,\mathrm{d}t + 2\frac{\mathrm{d}e(t)}{\mathrm{d}t}$$ 已知 $T=1\text{s}$，则 $K_p = 4$，$K_i = K_p\dfrac{T}{T_i} = 4\times\dfrac{1}{2} = 2$，$K_d = K_p\dfrac{T_d}{T} = 4\times\dfrac{0.5}{1} = 2$。
位置式数字 PID 控制算法： $$u(k) = 4e(k) + 2\sum_{j=1}^{k}e(j) + 2[e(k)-e(k-1)]$$
3分
增量式数字 PID 控制算法： $$\Delta u(k) = u(k) - u(k-1) = 4[e(k)-e(k-1)] + 2e(k) + 2[e(k)-2e(k-1)+e(k-2)]$$ $$= 8e(k) - 8e(k-1) + 2e(k-2)$$ 故递推公式为：$u(k) = u(k-1) + 8e(k) - 8e(k-1) + 2e(k-2)$。
2分
代入 $u(0)=0$，$e(-1)=0$，$e(0)=1$，$e(1)=0.5$，$e(2)=0.2$： $$u(1) = u(0) + 8e(1) - 8e(0) + 2e(-1) = 0 + 8\times 0.5 - 8\times 1 + 0 = -4$$ $$u(2) = u(1) + 8e(2) - 8e(1) + 2e(0) = -4 + 8\times 0.2 - 8\times 0.5 + 2\times 1 = -4.4$$
2分
三、（20分）离散控制系统结构如图一所示，其中采样周期 $T=1\text{s}$，广义被控对象的脉冲传递函数为： $$W_d(z) = \frac{0.500z^{-1}(1+0.250z^{-1})}{(1-z^{-1})(1-0.607z^{-1})}$$ （计算结果保留 3 位小数）

（1）试确定其对单位阶跃输入时的最小拍有纹波控制器 $D(z)$；（5分）

（2）试确定其对单位阶跃输入时的最小拍无纹波控制器 $D(z)$；（8分）

（3）检验（2）所设计的无纹波控制器 $D(z)$ 的控制输出 $u(k)$ 是否仍有纹波存在，并分别计算有纹波和无纹波两种情况下的调节时间 $t_s$。（7分）

解：

（1）设计最小拍有纹波控制器 $D(z)$：

简单对象，输入为单位阶跃信号（$m=1$），最小拍有纹波闭环脉冲传递函数 $W_B(z)$ 及 $1-W_B(z)$ 表达式为： $$W_B(z) = z^{-1}, \qquad 1 - W_B(z) = 1 - z^{-1}$$
2分
数字控制器 $D(z)$ 为： $$D(z) = \frac{1}{W_d(z)}\cdot\frac{W_B(z)}{1-W_B(z)} = \frac{(1-z^{-1})(1-0.607z^{-1})}{0.500z^{-1}(1+0.250z^{-1})}\cdot\frac{z^{-1}}{1-z^{-1}} = \frac{2.000(1-0.607z^{-1})}{1+0.250z^{-1}}$$ 这个 $D(z)$ 在物理上可以实现。
3分

（2）设计最小拍无纹波控制器 $D(z)$：

最小拍无纹波闭环脉冲传递函数 $W_B(z)$ 的表达式为： $$W_B(z) = f_1 z^{-1}(1 + 0.250z^{-1})$$ 其中 $f_1$ 为待定常数，由 $W_B(z)\big|_{z=1} = 1$ 得出： $$f_1(1 + 0.250) = 1 \implies f_1 = 0.800$$ 故： $$W_B(z) = 0.800z^{-1}(1 + 0.250z^{-1})$$ $$1 - W_B(z) = 1 - 0.800z^{-1}(1 + 0.250z^{-1}) = 1 - 0.800z^{-1} - 0.200z^{-2} = (1 - z^{-1})(1 + 0.200z^{-1})$$
4分
数字控制器 $D(z)$ 为： $$D(z) = \frac{1}{W_d(z)}\cdot\frac{W_B(z)}{1-W_B(z)} = \frac{(1-z^{-1})(1-0.607z^{-1})}{0.500z^{-1}(1+0.250z^{-1})}\cdot\frac{0.800z^{-1}(1+0.250z^{-1})}{(1-z^{-1})(1+0.200z^{-1})} = \frac{1.600(1-0.607z^{-1})}{1+0.200z^{-1}}$$ 这个 $D(z)$ 在物理上可以实现。
4分

（3）检验控制输出波动及计算两种情况下的调节时间 $t_s$：

无纹波控制器输出 $U(z)$ 为： $$U(z) = \frac{Y(z)}{W_d(z)} = \frac{W_B(z)}{W_d(z)}R(z) = \frac{0.800z^{-1}(1+0.250z^{-1})(1-z^{-1})(1-0.607z^{-1})}{0.500z^{-1}(1+0.250z^{-1})}\cdot\frac{1}{1-z^{-1}}$$ $$= 1.600(1 - 0.607z^{-1}) = 1.600 - 0.971z^{-1} + 0z^{-2} + \cdots$$ 控制器输出在 2 拍后恒为常数（没有波动），故系统输出响应不会有纹波。
4分
有纹波时： $$Y(z) = W_B(z)R(z) = z^{-1}\cdot\frac{1}{1-z^{-1}} = z^{-1} + z^{-2} + z^{-3} + \cdots$$ $y(1)=1$，$y(2)=1$，$y(3)=1,\cdots$，调节时间为 $t_s = 1T = 1\text{s}$。
无纹波时： $$Y(z) = W_B(z)R(z) = \frac{0.800z^{-1}(1+0.250z^{-1})}{1-z^{-1}} = \frac{0.800z + 0.200}{z^2 - z} = 0.800z^{-1} + 1.000z^{-2} + 1.000z^{-3} + \cdots$$ $y(1)=0.800$，$y(2)=1.000$，$y(3)=1.000,\cdots$，调节时间为 $t_s = 2T = 2\text{s}$。
3分
四、（20分）一个伺服电动机离散控制系统，其状态空间模型为： $$x(k+1) = \begin{bmatrix} 1 & 0.100 \\ 0 & 0.800 \end{bmatrix}x(k) + \begin{bmatrix} 0 \\ 1 \end{bmatrix}u(k)$$ $$y(k) = \begin{bmatrix} 1 & 0 \end{bmatrix}x(k)$$ 其中采样周期 $T=0.1\text{s}$，用观测状态反馈设计闭环控制系统（计算结果保留 3 位小数）。

（1）用分离性原理按极点配置计算状态反馈增益矩阵 $L = \begin{bmatrix} L_1 & L_2 \end{bmatrix}$，其中控制器的极点配置在 $z_{1,2} = 0.5 \pm j0.2$ 处（分别利用对应项系数相等和通用求解算法求解）；（7分）

（2）按极点配置计算预报观测器增益矩阵 $K = \begin{bmatrix} K_1 & K_2 \end{bmatrix}^T$，其中观测器的极点配置在 $z_{1,2} = 0.6$ 处（分别利用对应项系数相等和通用求解算法求解）；（7分）

（3）当系统初始状态为 $x(0)=\begin{bmatrix} 1 & 0 \end{bmatrix}^T$，观测器初始状态为 $\hat{x}(0)=\begin{bmatrix} 0 & 0 \end{bmatrix}^T$ 时，求状态重构误差 $\tilde{x}(1)$，并写出包含状态反馈和观测器在内的增广闭环系统特征方程 $\alpha(z)$，验证闭环极点是否已按要求正确配置。（6分）

解：

（1）按极点配置计算状态反馈增益矩阵 $L$：

已知 $F = \begin{bmatrix} 1 & 0.100 \\ 0 & 0.800 \end{bmatrix}$，$G = \begin{bmatrix} 0 \\ 1 \end{bmatrix}$。期望闭环控制极点为 $z_{1,2} = 0.5 \pm j0.2$，故期望特征多项式为： $$\alpha_c(z) = (z - 0.5 - j0.2)(z - 0.5 + j0.2) = z^2 - z + 0.290$$ 方法一（对应项系数相等法）： 设状态反馈矩阵 $L = \begin{bmatrix} L_1 & L_2 \end{bmatrix}$，则闭环系统特征多项式为： $$\alpha_c(z) = |zI - F + GL| = \left|z\begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} - \begin{bmatrix} 1 & 0.100 \\ 0 & 0.800 \end{bmatrix} + \begin{bmatrix} 0 \\ 1 \end{bmatrix}\begin{bmatrix} L_1 & L_2 \end{bmatrix}\right| = \begin{vmatrix} z-1 & -0.100 \\ L_1 & z-0.800+L_2 \end{vmatrix}$$ $$= z^2 + (L_2 - 1.800)z + (0.800 + 0.100L_1 - L_2) = z^2 - z + 0.290$$ 比较对应项系数解得： $$\begin{cases} L_2 - 1.800 = -1 \\ 0.800 + 0.100L_1 - L_2 = 0.290 \end{cases} \implies L = \begin{bmatrix} L_1 & L_2 \end{bmatrix} = \begin{bmatrix} 2.900 & 0.800 \end{bmatrix}$$
4分
方法二（通用求解算法）： $$L = \begin{bmatrix} L_1 & L_2 \end{bmatrix} = \begin{bmatrix} 0 & 1 \end{bmatrix}\begin{bmatrix} G & FG \end{bmatrix}^{-1}\alpha_c(F)$$ 其中 $\begin{bmatrix} G & FG \end{bmatrix} = \begin{bmatrix} 0 & 0.100 \\ 1 & 0.800 \end{bmatrix}$，$\begin{bmatrix} G & FG \end{bmatrix}^{-1} = \begin{bmatrix} -8.000 & 1.000 \\ 10.000 & 0 \end{bmatrix}$，且： $$\alpha_c(F) = \begin{bmatrix} 1 & 0.100 \\ 0 & 0.800 \end{bmatrix}^2 - \begin{bmatrix} 1 & 0.100 \\ 0 & 0.800 \end{bmatrix} + 0.290\begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} = \begin{bmatrix} 0.290 & 0.080 \\ 0 & 0.130 \end{bmatrix}$$ $$L = \begin{bmatrix} 0 & 1 \end{bmatrix}\begin{bmatrix} -8.000 & 1.000 \\ 10.000 & 0 \end{bmatrix}\begin{bmatrix} 0.290 & 0.080 \\ 0 & 0.130 \end{bmatrix} = \begin{bmatrix} 2.900 & 0.800 \end{bmatrix}$$
3分

（2）按极点配置计算预报观测器增益矩阵 $K$：

已知 $C = \begin{bmatrix} 1 & 0 \end{bmatrix}$，设观测器增益矩阵为 $K = \begin{bmatrix} K_1 \\ K_2 \end{bmatrix}$。预报观测器方程为： $$\hat{x}(k+1) = F\hat{x}(k) + Gu(k) + K[y(k) - C\hat{x}(k)]$$ 方法一（对应项系数相等法）： 状态重构误差的特征多项式为： $$\alpha_e(z) = |zI - F + KC| = \left|z\begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} - \begin{bmatrix} 1 & 0.100 \\ 0 & 0.800 \end{bmatrix} + \begin{bmatrix} K_1 \\ K_2 \end{bmatrix}\begin{bmatrix} 1 & 0 \end{bmatrix}\right| = \begin{vmatrix} z-1+K_1 & -0.100 \\ K_2 & z-0.800 \end{vmatrix}$$ $$= z^2 + (K_1 - 1.800)z + (0.800 - 0.800K_1 + 0.100K_2) = (z - 0.6)^2 = z^2 - 1.200z + 0.360$$ 解得： $$K = \begin{bmatrix} K_1 \\ K_2 \end{bmatrix} = \begin{bmatrix} 0.600 \\ 0.400 \end{bmatrix}$$
4分
方法二（通用求解算法）： $$K = \begin{bmatrix} K_1 \\ K_2 \end{bmatrix} = \alpha_e(F)\begin{bmatrix} C \\ CF \end{bmatrix}^{-1}\begin{bmatrix} 0 \\ 1 \end{bmatrix}$$ 其中 $\begin{bmatrix} C \\ CF \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ 1 & 0.100 \end{bmatrix}$，$\begin{bmatrix} C \\ CF \end{bmatrix}^{-1} = \begin{bmatrix} 1.000 & 0 \\ -10.000 & 10.000 \end{bmatrix}$，且： $$\alpha_e(F) = \begin{bmatrix} 1 & 0.100 \\ 0 & 0.800 \end{bmatrix}^2 - 1.200\begin{bmatrix} 1 & 0.100 \\ 0 & 0.800 \end{bmatrix} + 0.360I = \begin{bmatrix} 0.160 & 0.060 \\ 0 & 0.040 \end{bmatrix}$$ $$K = \begin{bmatrix} 0.160 & 0.060 \\ 0 & 0.040 \end{bmatrix}\begin{bmatrix} 1.000 & 0 \\ -10.000 & 10.000 \end{bmatrix}\begin{bmatrix} 0 \\ 1 \end{bmatrix} = \begin{bmatrix} 0.600 \\ 0.400 \end{bmatrix}$$
3分

（3）计算状态重构误差 $\tilde{x}(1)$ 及验证闭环系统极点配置：

状态重构误差方程为 $\tilde{x}(k+1) = x(k+1) - \hat{x}(k+1) = [F - KC]\tilde{x}(k)$，因此： $$\tilde{x}(1) = \left(\begin{bmatrix} 1 & 0.100 \\ 0 & 0.800 \end{bmatrix} - \begin{bmatrix} 0.600 \\ 0.400 \end{bmatrix}\begin{bmatrix} 1 & 0 \end{bmatrix}\right)\left(\begin{bmatrix} 1 \\ 0 \end{bmatrix} - \begin{bmatrix} 0 \\ 0 \end{bmatrix}\right) = \begin{bmatrix} 0.400 & 0.100 \\ -0.400 & 0.800 \end{bmatrix}\begin{bmatrix} 1 \\ 0 \end{bmatrix} = \begin{bmatrix} 0.400 \\ -0.400 \end{bmatrix}$$
3分
令整个闭环系统增广状态为 $z(k) = \begin{bmatrix} x(k) \\ \hat{x}(k) \end{bmatrix}$，代入控制律 $u(k) = -L\hat{x}(k) = \begin{bmatrix} -2.900 & -0.800 \end{bmatrix}\hat{x}(k)$，得闭环系统状态方程： $$z(k+1) = \begin{bmatrix} F & -GL \\ KC & F - GL - KC \end{bmatrix}z(k) = \begin{bmatrix} 1 & 0.100 & 0 & 0 \\ 0 & 0.800 & -2.900 & -0.800 \\ 0.600 & 0 & 0.400 & 0.100 \\ 0.400 & 0 & -3.300 & 0 \end{bmatrix}z(k) = \overline{F}z(k)$$ 对增广矩阵作初等行列变换（或直接展开行列式）得整个闭环系统的特征方程为： $$\alpha(z) = |zI - \overline{F}| = |zI - F + GL|\cdot|zI - F + KC| = (z^2 - z + 0.290)(z^2 - 1.200z + 0.360)$$ $$= (z - 0.6)^2 [z - (0.5 + j0.2)][z - (0.5 - j0.2)] = 0$$ 因此，闭环系统方程的极点已按要求正确配置。
3分
