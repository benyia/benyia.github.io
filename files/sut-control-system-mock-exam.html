一、（15分）离散控制系统如下图所示，其中采样周期 $T=0.5\text{s}$，零阶保持器 $W_{h0}(s)=\dfrac{1-e^{-sT}}{s}$，被控对象 $W(s)=\dfrac{2}{s+2}$。（计算结果保留 4 位小数）

试：

（1）当 $D(z)=1$ 时，求系统的开环脉冲传递函数 $W_d(z)$ 及闭环脉冲传递函数 $W_B(z)$；（5分）

（2）当 $D(z)=1$ 且输入为单位阶跃信号时，求系统输出 $Y(z)$、前三个采样周期时刻的值 $y(0)$、$y(1)$、$y(2)$、$y(3)$ 及通项表达式 $y(k)$；（6分）

（3）若数字控制器取比例控制 $D(z)=K_p$，试确定使闭环系统稳定的 $K_p$ 取值范围，并求出单位阶跃输入下的稳态误差 $e(\infty)$（用 $K_p$ 表示，并计算 $K_p=1$ 时的稳态误差值）。（4分）

解：

（1）求开环与闭环脉冲传递函数：

系统广义被控对象开环脉冲传递函数为（已知 $T=0.5\text{s}$，$e^{-2T}=e^{-1}\approx 0.3679$）： $$W_d(z) = \mathcal{Z}[W_{h0}(s)W(s)] = \mathcal{Z}\left(\frac{1-e^{-sT}}{s}\cdot\frac{2}{s+2}\right) = (1-z^{-1})\mathcal{Z}\left(\frac{2}{s(s+2)}\right)$$ $$= (1-z^{-1})\left[\frac{1}{1-z^{-1}} - \frac{1}{1-e^{-2T}z^{-1}}\right] = \frac{1-e^{-1}}{z-e^{-1}} = \frac{1-0.3679}{z-0.3679} = \frac{0.6321}{z-0.3679}$$
3分
当 $D(z)=1$ 时，系统闭环脉冲传递函数为： $$W_B(z) = \frac{D(z)W_d(z)}{1+D(z)W_d(z)} = \frac{\dfrac{0.6321}{z-0.3679}}{1+\dfrac{0.6321}{z-0.3679}} = \frac{0.6321}{z+0.2642}$$
2分

（2）求单位阶跃响应 $Y(z)$、采样时刻值及通项 $y(k)$：

当输入为单位阶跃信号 $R(z)=\dfrac{z}{z-1}$ 时，运用长除法求前几拍输出： $$Y(z) = W_B(z)R(z) = \frac{0.6321}{z+0.2642}\cdot\frac{z}{z-1} = \frac{0.6321z}{z^2 - 0.7358z - 0.2642}$$ $$= 0z^0 + 0.6321z^{-1} + 0.4651z^{-2} + 0.5092z^{-3} + \cdots$$ 故：$y(0)=0$，$y(1)=0.6321$，$y(2)=0.4651$，$y(3)=0.5092$。
3分
利用部分分式展开法求通项 $y(k)$： $$\frac{Y(z)}{z} = \frac{0.6321}{(z-1)(z+0.2642)} = \frac{0.6321}{1.2642}\left[\frac{1}{z-1} - \frac{1}{z+0.2642}\right] = 0.5000\left[\frac{1}{z-1} - \frac{1}{z+0.2642}\right]$$ $$Y(z) = 0.5000\left[\frac{z}{z-1} - \frac{z}{z+0.2642}\right] \implies y(k) = 0.5000\left[1 - (-0.2642)^k\right]\quad (k=0,1,2,\cdots)$$
3分

（3）分析 $D(z)=K_p$ 时的稳定性与稳态误差：

当 $D(z)=K_p$ 时，闭环特征方程为 $z - 0.3679 + 0.6321K_p = 0$，特征根为 $z = 0.3679 - 0.6321K_p$。
由闭环系统稳定条件 $|z| = |0.3679 - 0.6321K_p| < 1$，解得：$-1 < K_p < 2.1641$。
2分
当系统稳定时，由终值定理得单位阶跃输入下的稳态误差： $$e(\infty) = \lim_{z\to 1}(z-1)E(z) = \lim_{z\to 1}(z-1)\cdot\frac{z}{z-1}\cdot\frac{z-0.3679}{z-0.3679+0.6321K_p} = \frac{0.6321}{0.6321+0.6321K_p} = \frac{1}{1+K_p}$$ 可见当 $K_p$ 增大时稳态误差减小；当 $K_p=1$ 时，$e(\infty) = \dfrac{1}{1+1} = 0.5000$（或由 $1-y(\infty)=1-0.5000=0.5000$ 得出）。
2分
二、（15分）数字 PID 控制算法推导与计算。

已知连续系统的校正装置为模拟 PID 控制器：$D(s) = \dfrac{U(s)}{E(s)} = K_p\left(1 + \dfrac{1}{T_i s} + T_d s\right)$，采样周期为 $T$。

（1）写出模拟 PID 控制器的时域表达式 $u(t)$，并据此推导出位置式数字 PID 控制算法 $u(k)$ 及其脉冲传递函数 $D(z)=\dfrac{U(z)}{E(z)}$；（5分）

（2）基于位置式算法推导出增量式数字 PID 控制算法 $\Delta u(k)$；（3分）

（3）当给定参数为 $D(s) = 2\left(1 + \dfrac{1}{0.5s} + 0.25s\right)$，采样周期 $T=0.5\text{s}$，若系统初始时刻 $k=0$，控制器初始输出 $u(0)=0$，采样偏差依次为 $e(0)=1$、$e(1)=0.5$、$e(2)=0.2$（当 $k<0$ 时 $e(k)=0$），试分别计算控制器输出 $u(1)$ 和 $u(2)$；（4分）

（4）与位置式数字 PID 控制器相比，简要说明增量式数字 PID 控制算法的优势。（3分）

解：

（1）模拟 PID 时域形式与位置式数字 PID 算法：

模拟 PID 控制算法的时域表达式为： $$u(t) = K_p\left[e(t) + \frac{1}{T_i}\int_0^t e(t)\,\mathrm{d}t + T_d\frac{\mathrm{d}e(t)}{\mathrm{d}t}\right]$$
1分
以矩形向后差分近似积分、一阶向后差分近似微分，得到位置式数字 PID 控制算法： $$u(k) = K_p\left\{e(k) + \frac{T}{T_i}\sum_{j=1}^{k}e(j) + \frac{T_d}{T}[e(k)-e(k-1)]\right\} = K_p e(k) + K_i\sum_{j=1}^{k}e(j) + K_d[e(k)-e(k-1)]$$ 其中 $K_i = K_p\dfrac{T}{T_i}$，$K_d = K_p\dfrac{T_d}{T}$。
2分
对上式两边取 $Z$ 变换，可得位置式数字 PID 的脉冲传递函数： $$D(z) = \frac{U(z)}{E(z)} = K_p\left[1 + \frac{T}{T_i(1-z^{-1})} + \frac{T_d}{T}(1-z^{-1})\right] = K_p + K_i\frac{1}{1-z^{-1}} + K_d(1-z^{-1})$$
2分

（2）推导增量式数字 PID 控制算法：

由 $k-1$ 时刻的输出表达式 $u(k-1) = K_p e(k-1) + K_i\sum_{j=1}^{k-1}e(j) + K_d[e(k-1)-e(k-2)]$，两式相减得控制增量： $$\Delta u(k) = u(k) - u(k-1) = K_p[e(k)-e(k-1)] + K_i e(k) + K_d[e(k)-2e(k-1)+e(k-2)]$$ $$= (K_p + K_i + K_d)e(k) - (K_p + 2K_d)e(k-1) + K_d e(k-2)$$
3分

（3）代入具体参数计算 $u(1)$ 与 $u(2)$：

由 $D(s) = 2\left(1 + \dfrac{1}{0.5s} + 0.25s\right)$ 及 $T=0.5\text{s}$，可知：$K_p = 2$，$T_i = 0.5\text{s}$，$T_d = 0.25\text{s}$。
从而：$K_i = K_p\dfrac{T}{T_i} = 2\times\dfrac{0.5}{0.5} = 2$，$K_d = K_p\dfrac{T_d}{T} = 2\times\dfrac{0.25}{0.5} = 1$。
代入增量式递推公式： $$u(k) = u(k-1) + (2+2+1)e(k) - (2+2\times 1)e(k-1) + 1\cdot e(k-2) = u(k-1) + 5e(k) - 4e(k-1) + e(k-2)$$
2分
代入 $u(0)=0$，$e(-1)=0$，$e(0)=1$，$e(1)=0.5$，$e(2)=0.2$： $$u(1) = u(0) + 5e(1) - 4e(0) + e(-1) = 0 + 5\times 0.5 - 4\times 1 + 0 = -1.5$$ $$u(2) = u(1) + 5e(2) - 4e(1) + e(0) = -1.5 + 5\times 0.2 - 4\times 0.5 + 1 = -1.5$$
2分

（4）增量式数字 PID 控制算法的优势：

1）计算机只输出控制增量 $\Delta u(k)$（即执行机构位置的变化部分），因此计算机发生故障或误动作时影响较小，不会严重冲击生产过程；
2）在 $k$ 时刻计算输出只需用到当前偏差 $e(k)$ 及前两拍偏差 $e(k-1)$、$e(k-2)$，无需累加历史全部偏差，既避免了积分饱和，又节约了内存与计算时间；
3）在进行手动—自动无扰切换时，控制量冲击小，能够实现平滑过渡。
3分
三、（20分）离散控制系统结构如图一所示，其中广义被控对象的脉冲传递函数为 $$W_d(z) = \frac{0.250z^{-1}(1+0.600z^{-1})}{(1-z^{-1})(1-0.500z^{-1})}$$ 采样周期 $T=1\text{s}$。（计算结果保留 3 位小数）

（1）试确定该系统在单位阶跃输入时的最小拍有纹波数字控制器 $D(z)$；（5分）

（2）试确定该系统在单位阶跃输入时的最小拍无纹波数字控制器 $D(z)$；（8分）

（3）针对（2）所设计的最小拍无纹波控制器，计算控制量序列 $u(k)$ 以检验其是否仍有纹波存在，并分别给出有纹波和无纹波两种情况下的调节时间 $t_s$。（7分）

解：

（1）设计最小拍有纹波数字控制器 $D(z)$：

广义对象纯滞后拍数 $d=1$，无单位圆上及圆外零极点（除 $z=1$ 极点外），对单位阶跃输入 $R(z)=\dfrac{1}{1-z^{-1}}$（$m=1$），最小拍有纹波闭环脉冲传递函数为： $$W_B(z) = z^{-1}, \qquad 1 - W_B(z) = 1 - z^{-1}$$
2分
由此求得最小拍有纹波数字控制器为： $$D(z) = \frac{1}{W_d(z)}\cdot\frac{W_B(z)}{1-W_B(z)} = \frac{(1-z^{-1})(1-0.500z^{-1})}{0.250z^{-1}(1+0.600z^{-1})}\cdot\frac{z^{-1}}{1-z^{-1}} = \frac{4.000(1-0.500z^{-1})}{1+0.600z^{-1}}$$ 该 $D(z)$ 在物理上可以实现。
3分

（2）设计最小拍无纹波数字控制器 $D(z)$：

为消除采样点间的纹波，$W_B(z)$ 必须包含 $W_d(z)$ 的全部零点因子 $(1+0.600z^{-1})$，故设闭环脉冲传递函数为： $$W_B(z) = f_1 z^{-1}(1 + 0.600z^{-1})$$ 由无稳态误差条件 $W_B(z)\big|_{z=1} = 1$，得： $$f_1(1 + 0.600) = 1 \implies f_1 = 0.625$$ 故： $$W_B(z) = 0.625z^{-1}(1 + 0.600z^{-1}) = 0.625z^{-1} + 0.375z^{-2}$$
4分
进而求得误差传递函数因子： $$1 - W_B(z) = 1 - 0.625z^{-1} - 0.375z^{-2} = (1 - z^{-1})(1 + 0.375z^{-1})$$ 最小拍无纹波数字控制器 $D(z)$ 为： $$D(z) = \frac{1}{W_d(z)}\cdot\frac{W_B(z)}{1-W_B(z)} = \frac{(1-z^{-1})(1-0.500z^{-1})}{0.250z^{-1}(1+0.600z^{-1})}\cdot\frac{0.625z^{-1}(1+0.600z^{-1})}{(1-z^{-1})(1+0.375z^{-1})} = \frac{2.500(1-0.500z^{-1})}{1+0.375z^{-1}}$$ 该 $D(z)$ 在物理上可以实现。
4分

（3）检验控制量 $u(k)$ 波动及计算两种情况下的调节时间 $t_s$：

无纹波设计下，控制器输出 $U(z)$ 为： $$U(z) = \frac{W_B(z)}{W_d(z)}R(z) = \frac{0.625z^{-1}(1+0.600z^{-1})(1-z^{-1})(1-0.500z^{-1})}{0.250z^{-1}(1+0.600z^{-1})}\cdot\frac{1}{1-z^{-1}}$$ $$= 2.500(1 - 0.500z^{-1}) = 2.500 - 1.250z^{-1} + 0z^{-2} + 0z^{-3} + \cdots$$ 由于 $k\ge 2$ 后控制序列恒为常数（$u(2)=u(3)=\cdots=0$），控制器输出收敛无衰减振荡，故系统输出响应不会有纹波。
4分
有纹波时： $Y(z) = W_B(z)R(z) = z^{-1}\cdot\dfrac{1}{1-z^{-1}} = z^{-1} + z^{-2} + z^{-3} + \cdots$，$y(1)=y(2)=\cdots=1$，调节时间为 $t_s = 1T = 1\text{s}$。
无纹波时： $Y(z) = 0.625z^{-1}(1+0.600z^{-1})\cdot\dfrac{1}{1-z^{-1}} = 0.625z^{-1} + 1.000z^{-2} + 1.000z^{-3} + \cdots$，$y(1)=0.625$，$y(2)=y(3)=\cdots=1.000$，调节时间为 $t_s = 2T = 2\text{s}$。
3分
四、（20分）某离散控制系统状态空间模型为： $$x(k+1) = \begin{bmatrix} 0.800 & 0.200 \\ -0.100 & 0.600 \end{bmatrix}x(k) + \begin{bmatrix} 0 \\ 1 \end{bmatrix}u(k)$$ $$y(k) = \begin{bmatrix} 1 & 0 \end{bmatrix}x(k)$$ （计算结果保留 3 位小数）

（1）用 Jury（朱利）稳定性判据判断开环系统的稳定性；（4分）

（2）若要求将状态反馈控制器的极点配置在 $z_{1,2} = 0.4 \pm j0.3$ 处，试按全部状态可测时，计算状态反馈增益矩阵 $L = \begin{bmatrix} L_1 & L_2 \end{bmatrix}$（分别利用对应项系数相等法和通用求解算法求解）；（8分）

（3）按极点配置设计预报观测器，将观测器的极点配置在 $z_{1,2} = 0.3$ 处，计算观测器增益矩阵 $K = \begin{bmatrix} K_1 & K_2 \end{bmatrix}^T$（分别利用对应项系数相等法和通用求解算法求解）；若系统初始状态 $x(0)=\begin{bmatrix} 1 & 0 \end{bmatrix}^T$，观测器初始状态 $\hat{x}(0)=\begin{bmatrix} 0 & 0 \end{bmatrix}^T$，求状态重构误差 $\tilde{x}(1)$。（8分）

解：

（1）用 Jury 稳定性判据判断开环系统稳定性：

系统矩阵 $F = \begin{bmatrix} 0.800 & 0.200 \\ -0.100 & 0.600 \end{bmatrix}$，$G = \begin{bmatrix} 0 \\ 1 \end{bmatrix}$，$C = \begin{bmatrix} 1 & 0 \end{bmatrix}$。开环特征方程为： $$F(z) = |zI - F| = \begin{vmatrix} z-0.800 & -0.200 \\ 0.100 & z-0.600 \end{vmatrix} = z^2 - 1.400z + 0.500 = 0$$ 这里阶数 $n=2$，$a_2 = 1$，$a_1 = -1.400$，$a_0 = 0.500$。朱利阵列为：
$z^0$$z^1$$z^2$
$0.500$$-1.400$$1$
检验朱利判据条件：
① $F(1) = 1 - 1.400 + 0.500 = 0.100 > 0$；
② $(-1)^n F(-1) = (-1)^2(1 + 1.400 + 0.500) = 2.900 > 0$；
③ $|a_0| = 0.500 < 1 = a_2$。
故开环系统稳定。
4分

（2）状态反馈极点配置求解反馈增益矩阵 $L$：

期望闭环极点为 $z_{1,2} = 0.4 \pm j0.3$，故期望特征多项式为： $$\alpha_c(z) = (z - 0.4 - j0.3)(z - 0.4 + j0.3) = (z-0.4)^2 + 0.3^2 = z^2 - 0.800z + 0.250$$ 方法一（对应项系数相等法）： 设 $L = \begin{bmatrix} L_1 & L_2 \end{bmatrix}$，则闭环特征多项式为： $$\alpha_c(z) = |zI - F + GL| = \begin{vmatrix} z-0.800 & -0.200 \\ 0.100+L_1 & z-0.600+L_2 \end{vmatrix}$$ $$= (z-0.800)(z-0.600+L_2) + 0.200(0.100+L_1) = z^2 + (L_2 - 1.400)z + (0.500 + 0.200L_1 - 0.800L_2)$$ 令其与 $z^2 - 0.800z + 0.250$ 对应项系数相等： $$\begin{cases} L_2 - 1.400 = -0.800 \\ 0.500 + 0.200L_1 - 0.800L_2 = 0.250 \end{cases} \implies L = \begin{bmatrix} L_1 & L_2 \end{bmatrix} = \begin{bmatrix} 1.150 & 0.600 \end{bmatrix}$$
4分
方法二（通用求解算法 / Ackermann 公式）： $$\begin{bmatrix} G & FG \end{bmatrix} = \begin{bmatrix} 0 & 0.200 \\ 1 & 0.600 \end{bmatrix}, \qquad \begin{bmatrix} G & FG \end{bmatrix}^{-1} = \begin{bmatrix} -3.000 & 1.000 \\ 5.000 & 0 \end{bmatrix}$$ $$\alpha_c(F) = F^2 - 0.800F + 0.250I = \begin{bmatrix} 0.620 & 0.280 \\ -0.140 & 0.340 \end{bmatrix} - \begin{bmatrix} 0.640 & 0.160 \\ -0.080 & 0.480 \end{bmatrix} + \begin{bmatrix} 0.250 & 0 \\ 0 & 0.250 \end{bmatrix} = \begin{bmatrix} 0.230 & 0.120 \\ -0.060 & 0.110 \end{bmatrix}$$ $$L = \begin{bmatrix} 0 & 1 \end{bmatrix}\begin{bmatrix} G & FG \end{bmatrix}^{-1}\alpha_c(F) = \begin{bmatrix} 5.000 & 0 \end{bmatrix}\begin{bmatrix} 0.230 & 0.120 \\ -0.060 & 0.110 \end{bmatrix} = \begin{bmatrix} 1.150 & 0.600 \end{bmatrix}$$
4分

（3）预报观测器极点配置求解 $K$ 及状态重构误差 $\tilde{x}(1)$：

观测器期望极点配置在 $z_{1,2}=0.3$ 处，故观测器期望特征多项式为： $$\alpha_e(z) = (z - 0.3)^2 = z^2 - 0.600z + 0.090$$ 方法一（对应项系数相等法）： 设 $K = \begin{bmatrix} K_1 & K_2 \end{bmatrix}^T$，预报观测器状态重构误差特征多项式为： $$\alpha_e(z) = |zI - F + KC| = \begin{vmatrix} z-0.800+K_1 & -0.200 \\ 0.100+K_2 & z-0.600 \end{vmatrix}$$ $$= (z-0.800+K_1)(z-0.600) + 0.200(0.100+K_2) = z^2 + (K_1 - 1.400)z + (0.500 - 0.600K_1 + 0.200K_2)$$ 与 $z^2 - 0.600z + 0.090$ 对应系数比较得： $$\begin{cases} K_1 - 1.400 = -0.600 \\ 0.500 - 0.600K_1 + 0.200K_2 = 0.090 \end{cases} \implies K = \begin{bmatrix} K_1 \\ K_2 \end{bmatrix} = \begin{bmatrix} 0.800 \\ 0.350 \end{bmatrix}$$
3分
方法二（通用求解算法）： $$\begin{bmatrix} C \\ CF \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ 0.800 & 0.200 \end{bmatrix}, \qquad \begin{bmatrix} C \\ CF \end{bmatrix}^{-1} = \begin{bmatrix} 1.000 & 0 \\ -4.000 & 5.000 \end{bmatrix}$$ $$\alpha_e(F) = F^2 - 0.600F + 0.090I = \begin{bmatrix} 0.620 & 0.280 \\ -0.140 & 0.340 \end{bmatrix} - \begin{bmatrix} 0.480 & 0.120 \\ -0.060 & 0.360 \end{bmatrix} + \begin{bmatrix} 0.090 & 0 \\ 0 & 0.090 \end{bmatrix} = \begin{bmatrix} 0.230 & 0.160 \\ -0.080 & 0.070 \end{bmatrix}$$ $$K = \alpha_e(F)\begin{bmatrix} C \\ CF \end{bmatrix}^{-1}\begin{bmatrix} 0 \\ 1 \end{bmatrix} = \begin{bmatrix} 0.230 & 0.160 \\ -0.080 & 0.070 \end{bmatrix}\begin{bmatrix} 0 \\ 5.000 \end{bmatrix} = \begin{bmatrix} 0.800 \\ 0.350 \end{bmatrix}$$
3分
求状态重构误差 $\tilde{x}(1)$： 状态重构误差方程为 $\tilde{x}(k+1) = (F - KC)\tilde{x}(k)$，因此： $$\tilde{x}(1) = (F - KC)[x(0) - \hat{x}(0)] = \left(\begin{bmatrix} 0.800 & 0.200 \\ -0.100 & 0.600 \end{bmatrix} - \begin{bmatrix} 0.800 & 0 \\ 0.350 & 0 \end{bmatrix}\right)\begin{bmatrix} 1 \\ 0 \end{bmatrix} = \begin{bmatrix} 0 & 0.200 \\ -0.450 & 0.600 \end{bmatrix}\begin{bmatrix} 1 \\ 0 \end{bmatrix} = \begin{bmatrix} 0 \\ -0.450 \end{bmatrix}$$
2分
