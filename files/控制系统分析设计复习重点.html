第一章 自动控制基础

1. 什么是自动控制、基本概念

自动控制：在没有人直接参与的情况下，利用控制装置，使被控对象的被控量自动按照预定规律运行，并抵消外部扰动的影响。

  • 被控对象：被控制的设备、装置或过程。
  • 被控量（输出）：需要被控制、维持的物理量。
  • 参考输入（给定输入）：期望被控量达到的目标值。
  • 扰动：引起输出偏离期望值的内外干扰。
  • 控制器：接收偏差信号，产生控制信号驱动执行机构。
  • 执行机构：直接对被控对象施加控制作用。
  • 反馈：把输出测量出来送回输入端，与参考输入比较得到偏差。
闭环（反馈）控制的核心：利用偏差消除偏差。开环控制没有反馈，输出不影响控制输入。

2. 稳定性的重要性（简答题高频）

  • 首要前提：不稳定系统输出发散、振荡越来越大，根本无法完成控制任务。
  • 抗扰动能力：稳定系统受干扰后能回到平衡点；不稳定系统扰动会被不断放大。
  • 性能基础：只有系统稳定，讨论超调量、调节时间、稳态误差才有意义；不稳定系统没有性能指标可言。
  • 设备安全：不稳定会造成机械超限、器件损坏，引发安全事故。

3. 瞬态响应（瞬态效应）与稳态响应

  • 瞬态响应（瞬态效应）：输入变化后，系统从旧平衡状态向新平衡状态过渡的暂时分量；包含超调、振荡、调节时间，随时间衰减。
  • 稳态响应：t → ∞ 时，瞬态分量完全消失后系统长期保持的输出；用来评价稳态误差。
完整输出 = 瞬态响应分量 + 稳态响应分量

第二章 系统数学模型（分值最高）

1. 传递函数反映了系统的什么特性

定义：零初始条件下，输出的拉普拉斯变换与输入的拉普拉斯变换之比。仅适用于线性定常系统。

G(s) = Y(s)R(s)
  • 反映系统固有的动态特性，只取决于系统结构、元件参数，与输入信号、初始条件无关。
  • 通过零点、极点分布，可以反映系统的稳定性、瞬态响应、稳态响应。
  • 仅描述输入输出的外部关系，不能反映系统内部状态。
  • 只代表零状态响应；完整输出还要叠加初始条件带来的零输入响应。

2. 线性系统与非线性系统；线性系统满足的条件

线性系统必须同时满足叠加性和齐次性（比例性）。

  • 叠加性：若输入 x1 → y1，x2 → y2，则输入 x1 + x2，输出为 y1 + y2。
  • 齐次性：若输入 x → y，则输入 βx，输出为 βy。

非线性系统：微分方程含有平方、乘积、饱和、死区、摩擦等非线性项，不满足叠加原理。现实绝大多数物理系统本质是非线性的，可以在工作点附近做小信号泰勒一阶线性近似。

3. 框图化简求传递函数（计算题重点）

  • 基础连接：串联、并联、负反馈、正反馈。
  • 掌握：相加点前移 / 后移；分支点前移 / 后移。
  • 复杂框图可以转成信号流图，用梅森增益公式直接求解，不必一步步化简。

负反馈闭环：

T(s) = G(s)1 + G(s)H(s)

正反馈闭环：

T(s) = G(s)1 − G(s)H(s)

梅森增益公式：

T = Σ Pk · ΔkΔ Δ = 1 − Σ Li + Σ LiLj（两两互不接触回路）− …
  • Pk：第 k 条前向通路的增益。
  • Δ：流图的特征式。
  • Δk：第 k 条通路的余因式，即删除所有与该通路接触的回路后，特征式剩余的部分。

4. 二阶系统：阻尼比 ζ 不同取值对应的响应（填空、简答高频）

二阶系统标准特征方程：

s² + 2ζωns + ωn² = 0 s1,2 = −ζωn ± ωn√(ζ² − 1)
阻尼比 ζ 系统状态 极点位置 阶跃响应特点
ζ = 0 无阻尼 一对纯虚极点 等幅持续振荡，临界稳定，不会衰减
0 < ζ < 1 欠阻尼 s 左半平面共轭复极点 衰减振荡，存在超调；工程中最常用
ζ = 1 临界阻尼 二重相等负实极点 无振荡无超调；刚好不发生振荡的边界；非振荡响应中最快
ζ > 1 过阻尼 两个不等负实极点 无振荡无超调；响应缓慢
复习做题建议：动手完成课本课后的框图化简、梅森公式、二阶系统分析习题。

第四章 反馈控制系统特性（计算题重点）

分清两个"灵敏度"，考试极易混淆：
  1. Bode 参数灵敏度：课后计算题，求偏导计算。
  2. 灵敏度函数 S(s)、补灵敏度函数 T(s)：填空简答，满足 S(s) + T(s) = 1。

1. Bode 参数灵敏度（课后习题计算题）

描述闭环传递函数 T 对某一参数 α 的敏感程度，等于相对变化率之比。

SαT = ∂T / T∂α / α = αT · ∂T∂α
  • 物理含义：参数 α 变化 1%，闭环传递函数 T 大约变化 SαT %。
  • 引入闭环反馈可以降低系统对对象参数变化的灵敏度。
  • 做题步骤：写出闭环传递函数 → 对参数 α 求偏导 → 代入公式化简。

2. 灵敏度函数与补灵敏度函数

单位负反馈，开环传递函数 L(s) = G(s)H(s)。

S(s) = 11 + L(s) T(s) = L(s)1 + L(s) S(s) + T(s) = 1
  • 灵敏度函数 S(s)：描述输出扰动对输出的传递，代表系统抑制扰动的能力。
  • 补灵敏度函数 T(s)：等于闭环传递函数，描述系统跟踪参考输入的能力。

3. 静态误差系数 Kp、Kv、Ka（老师上课画方框重点）

Kp = lims→0 L(s)，   ess = 11 + Kp  （阶跃输入） Kv = lims→0 sL(s)，   ess = 1Kv  （斜坡输入） Ka = lims→0 s²L(s)，   ess = 1Ka  （抛物线输入）
  • 0 型系统：只有有限的 Kp；I 型系统：有限的 Kv；II 型系统：有限的 Ka。
  • 题型：给定开环传递函数，求不同输入下的稳态误差。

智能控制：BP神经网络与模糊控制（只考概念，无复杂计算）

1. BP神经网络

  • BP 是反向传播误差的多层前馈神经网络。
  • 想要网络控制效果足够好，必须有足够多、具有代表性的训练样本；样本不足会发生欠拟合或过拟合。

2. 模糊控制基础概念

  • 模糊概念：现实中很多事物没有明确的"是 / 非"二值边界（大、小、高、低）。
  • 模糊集合：边界不清晰的集合；元素属于集合的程度取值在 0 ~ 1 之间。
  • 隶属度函数 μ(x)：μ(x) ∈ [0, 1]，描述元素 x 属于该模糊集合的程度；0 表示完全不属于，1 表示完全属于。常见类型：三角形、梯形、高斯型。

模糊集合三大组成要素：论域、模糊语言子集、隶属度函数。

  • 论域：全部讨论元素的全集。
  • 模糊语言子集（语言值）：如 {负大、负小、零、正小、正大}。
  • 隶属度函数：每一个语言值对应一条隶属度曲线。
专家系统：时间紧张可以简单浏览，不作为复习重点。

考试答题技巧

  1. 开放性简答题：没有固定标准答案，尽量多写相关知识点，写对就给分，不要空题。
  2. 填空、选择题：全部为基础概念，不要过度解读题目。
  3. 计算题：重视步骤分，即使最终结果算错，写出公式也能拿到部分分数。
  4. 复习范围：计算题只做课上练习、课后习题，不要钻研偏题怪题。
