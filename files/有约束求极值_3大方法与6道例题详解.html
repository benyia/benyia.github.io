一、K-T 条件（库恩-塔克条件 / Kuhn-Tucker Conditions）

【核心原理与标准做题步骤】

考虑标准形式的有约束优化问题（本文统一采用 $g_i(x) \le 0$ 形式；若教材采用 $g_i(x) \ge 0$，则拉格朗日函数写为 $L = f - \sum \lambda_i g_i$）： $$\min f(x) \quad \text{s.t.} \quad g_i(x) \le 0 \; (i=1,\dots,m), \quad h_j(x) = 0 \; (j=1,\dots,l)$$ 求解 K-T 点（极小值必要条件，凸规划下为充要条件）的标准步骤如下：

  1. 化为标准形式：将所有不等式约束整理为 $g_i(x) \le 0$，等式约束整理为 $h_j(x) = 0$。
  2. 构造拉格朗日函数：引入拉格朗日乘子 $\lambda_i \ge 0$ 和 $\mu_j \in \mathbb{R}$： $$L(x, \lambda, \mu) = f(x) + \sum_{i=1}^m \lambda_i g_i(x) + \sum_{j=1}^l \mu_j h_j(x)$$
  3. 列出 K-T 条件方程组：
    • 一阶驻点条件：$\nabla_x L(x, \lambda, \mu) = \nabla f(x) + \sum_{i=1}^m \lambda_i \nabla g_i(x) + \sum_{j=1}^l \mu_j \nabla h_j(x) = 0$
    • 互补松弛条件：$\lambda_i g_i(x) = 0 \quad (i=1,2,\dots,m)$
    • 原始可行性条件：$g_i(x) \le 0, \quad h_j(x) = 0$
    • 乘子非负条件：$\lambda_i \ge 0 \quad (i=1,2,\dots,m)$
  4. 分情况讨论求解：根据互补松弛条件 $\lambda_i g_i(x) = 0$，按乘子 $\lambda_i = 0$（非起作用约束，内部点）或 $g_i(x) = 0$（起作用约束，边界点）分类讨论，并检验是否同时满足 $g_i(x) \le 0$ 和 $\lambda_i \ge 0$。
例题 1.1（单个不等式约束的 K-T 点求解）
利用 K-T 条件求解非线性规划问题： $$\min f(x_1, x_2) = (x_1 - 2)^2 + (x_2 - 1)^2$$ $$\text{s.t.} \quad x_1 + x_2 \le 1$$
【详细解题步骤】
第1步（化为标准形式并构造拉格朗日函数）：
将不等式约束写为标准形式 $g(x_1, x_2) = x_1 + x_2 - 1 \le 0$。
引入乘子 $\lambda \ge 0$，构造拉格朗日函数： $$L(x_1, x_2, \lambda) = (x_1 - 2)^2 + (x_2 - 1)^2 + \lambda(x_1 + x_2 - 1)$$
第2步（写出 K-T 条件方程组）：
$$\begin{cases} \frac{\partial L}{\partial x_1} = 2(x_1 - 2) + \lambda = 0 & (1) \\[4pt] \frac{\partial L}{\partial x_2} = 2(x_2 - 1) + \lambda = 0 & (2) \\[4pt] \lambda(x_1 + x_2 - 1) = 0 & (3) \\[4pt] x_1 + x_2 - 1 \le 0 & (4) \\[4pt] \lambda \ge 0 & (5) \end{cases}$$
第3步（按互补松弛条件 (3) 分情况讨论）：
  • 情况一：令 $\lambda = 0$（约束不起作用）：
    代入 (1)、(2) 得：$2(x_1 - 2) = 0 \implies x_1 = 2$；$2(x_2 - 1) = 0 \implies x_2 = 1$。
    检验可行性条件 (4)：$g(2, 1) = 2 + 1 - 1 = 2 > 0$，不满足 $x_1 + x_2 - 1 \le 0$，故舍去！
  • 情况二：令 $x_1 + x_2 - 1 = 0$（约束起作用）：
    由 (1) 和 (2) 得：$x_1 = 2 - \frac{\lambda}{2}$，$x_2 = 1 - \frac{\lambda}{2}$。
    代入 $x_1 + x_2 - 1 = 0$ 得： $$\left(2 - \frac{\lambda}{2}\right) + \left(1 - \frac{\lambda}{2}\right) - 1 = 0 \implies 2 - \lambda = 0 \implies \lambda = 2$$ 检验乘子条件 (5)：$\lambda = 2 \ge 0$，满足要求。
    回代求得坐标：$x_1 = 2 - \frac{2}{2} = 1$，$x_2 = 1 - \frac{2}{2} = 0$。
结论：该问题的唯一 K-T 点为 $x^* = (1, 0)^T$，对应乘子 $\lambda^* = 2$。因目标函数为严格凸函数且约束为线性凸集，故 $x^* = (1, 0)^T$ 即为全局极小点，极小值 $f(x^*) = (1-2)^2 + (0-1)^2 = 2$。
例题 1.2（含两个不等式约束的 K-T 条件求解）
利用 K-T 条件求解有约束极值问题： $$\min f(x_1, x_2) = x_1^2 + x_2^2 - 4x_1 - 4x_2$$ $$\text{s.t.} \quad \begin{cases} x_1 + x_2 \le 2 \\ x_1 \ge 0 \end{cases}$$
【详细解题步骤】
第1步（化为标准形式并写出 K-T 条件）：
将两个不等式约束化为标准形式：$g_1(x) = x_1 + x_2 - 2 \le 0$，$g_2(x) = -x_1 \le 0$。
构造拉格朗日函数：$L(x_1, x_2, \lambda_1, \lambda_2) = x_1^2 + x_2^2 - 4x_1 - 4x_2 + \lambda_1(x_1 + x_2 - 2) + \lambda_2(-x_1)$。
列出 K-T 条件： $$\begin{cases} \frac{\partial L}{\partial x_1} = 2x_1 - 4 + \lambda_1 - \lambda_2 = 0 & (1) \\[4pt] \frac{\partial L}{\partial x_2} = 2x_2 - 4 + \lambda_1 = 0 & (2) \\[4pt] \lambda_1(x_1 + x_2 - 2) = 0, \quad \lambda_2(-x_1) = 0 & (3) \\[4pt] x_1 + x_2 - 2 \le 0, \quad -x_1 \le 0 & (4) \\[4pt] \lambda_1 \ge 0, \quad \lambda_2 \ge 0 & (5) \end{cases}$$
第2步（对互补松弛条件进行组合讨论）：
  • 情形 1（$\lambda_1 = 0, \lambda_2 = 0$）：由 (1)(2) 得 $x_1 = 2, x_2 = 2$。代入 $g_1$ 得 $2+2-2 = 2 > 0$，违背约束 (4)，舍去。
  • 情形 2（$\lambda_1 > 0, \lambda_2 = 0$，即 $x_1 + x_2 - 2 = 0$）：
    由 (1)(2) 知 $2x_1 - 4 + \lambda_1 = 0$ 且 $2x_2 - 4 + \lambda_1 = 0$，故 $x_1 = x_2$。
    代入 $x_1 + x_2 = 2$ 得 $x_1 = 1, x_2 = 1$。
    回代求乘子：$\lambda_1 = 4 - 2(1) = 2 > 0$。
    检验第2个约束：$-x_1 = -1 \le 0$ 成立。所有 K-T 条件全部满足！
  • 情形 3（$\lambda_1 = 0, \lambda_2 > 0$，即 $x_1 = 0$）：
    由 (1) 得 $-4 - \lambda_2 = 0 \implies \lambda_2 = -4 < 0$，违背 $\lambda_2 \ge 0$，舍去。
  • 情形 4（$\lambda_1 > 0, \lambda_2 > 0$，即 $x_1 = 0$ 且 $x_1 + x_2 = 2$）：
    解得 $x_1 = 0, x_2 = 2$。代入 (2) 得 $\lambda_1 = 4 - 2(2) = 0$，代入 (1) 得 $\lambda_2 = -4 < 0$，违背非负条件，舍去。
结论：K-T 点为 $x^* = (1, 1)^T$，对应拉格朗日乘子 $\lambda^* = (2, 0)^T$，极小值 $f(x^*) = 1 + 1 - 4 - 4 = -6$。
二、SUMT 外点法（序列无约束极小化 —— 外点罚函数法）

【核心原理与标准做题步骤】

外点罚函数法（Exterior Penalty Method）将约束违反量转化为惩罚项加到目标函数上，从而把有约束问题转化为一系列无约束问题。迭代点通常从可行域外部逐渐逼近最优解（可同时处理等式约束与不等式约束）：

  1. 构造外点罚函数（增广目标函数）：对于 $\min f(x) \quad \text{s.t.} \; g_i(x) \le 0, \; h_j(x) = 0$，取罚因子 $M_k > 0$（递增序列 $M_1 < M_2 < \dots \to +\infty$），构造： $$P(x, M_k) = f(x) + M_k \sum_{i=1}^m \left[\max\{0, g_i(x)\}\right]^2 + M_k \sum_{j=1}^l \left[h_j(x)\right]^2$$
  2. 求解无约束极小点 $x^*(M_k)$：对 $P(x, M_k)$ 求关于 $x$ 的梯度并令其为 $0$： $$\nabla_x P(x, M_k) = 0$$ 解出含罚因子 $M_k$ 的解析驻点 $x^*(M_k)$（对于不等式约束，在外点区域 $\max\{0, g_i(x)\} = g_i(x)$）。
  3. 求极限得原问题最优解：令罚因子 $M_k \to +\infty$，计算极限： $$x^* = \lim_{M_k \to +\infty} x^*(M_k)$$
例题 2.1（等式约束问题的 SUMT 外点法求解）
用 SUMT 外点罚函数法求解等式约束优化问题： $$\min f(x_1, x_2) = x_1^2 + 2x_2^2$$ $$\text{s.t.} \quad x_1 + x_2 = 1$$
【详细解题步骤】
第1步（构造外点罚函数 $P(x_1, x_2, M)$）：
将等式约束写为 $h(x_1, x_2) = x_1 + x_2 - 1 = 0$。引入罚因子 $M > 0$，构造增广目标函数： $$P(x_1, x_2, M) = x_1^2 + 2x_2^2 + M(x_1 + x_2 - 1)^2$$
第2步（求解无约束极值条件 $\nabla_x P = 0$）：
分别对 $x_1, x_2$ 求偏导并令其等于 $0$： $$\begin{cases} \frac{\partial P}{\partial x_1} = 2x_1 + 2M(x_1 + x_2 - 1) = 0 & (1) \\[4pt] \frac{\partial P}{\partial x_2} = 4x_2 + 2M(x_1 + x_2 - 1) = 0 & (2) \end{cases}$$ 用 (1) 式减去 (2) 式消去含 $M$ 的项： $$2x_1 - 4x_2 = 0 \implies x_1 = 2x_2$$ 将 $x_1 = 2x_2$ 代回 (2) 式： $$4x_2 + 2M(2x_2 + x_2 - 1) = 0 \implies (2 + 3M)x_2 = M$$ 解得关于罚因子 $M$ 的无约束极小点 $x^*(M)$： $$x_2^*(M) = \frac{M}{3M + 2}, \quad x_1^*(M) = \frac{2M}{3M + 2}$$ （注：可见对任意有限 $M > 0$，$x_1^*(M) + x_2^*(M) = \frac{3M}{3M+2} < 1$，均不满足等式约束，即位于可行集外部。）
第3步（令 $M \to +\infty$ 取极限求最优解）：
$$x_1^* = \lim_{M \to +\infty} \frac{2M}{3M + 2} = \lim_{M \to +\infty} \frac{2}{3 + \frac{2}{M}} = \frac{2}{3}$$ $$x_2^* = \lim_{M \to +\infty} \frac{M}{3M + 2} = \lim_{M \to +\infty} \frac{1}{3 + \frac{2}{M}} = \frac{1}{3}$$
结论：原问题的极小点为 $x^* = \left(\frac{2}{3}, \frac{1}{3}\right)^T$，极小值为 $f(x^*) = \left(\frac{2}{3}\right)^2 + 2\left(\frac{1}{3}\right)^2 = \frac{2}{3}$。
例题 2.2（不等式约束问题的 SUMT 外点法求解）
用 SUMT 外点罚函数法求解不等式约束优化问题： $$\min f(x_1, x_2) = x_1^2 + x_2^2$$ $$\text{s.t.} \quad x_1 + x_2 \ge 2$$
【详细解题步骤】
第1步（化为标准形式并分析无约束极小点位置）：
将约束化为 $g(x_1, x_2) = 2 - x_1 - x_2 \le 0$。
容易看出，原目标函数 $f(x_1, x_2) = x_1^2 + x_2^2$ 的无约束极小点为 $(0, 0)^T$，位于可行域外部（因 $g(0, 0) = 2 > 0$）。故外点法迭代点必落在不可行域 $g(x_1, x_2) > 0$ 内，此时 $\max\{0, 2 - x_1 - x_2\} = 2 - x_1 - x_2$。
第2步（构造外点罚函数并求无约束极小点）：
在不可行域 $2 - x_1 - x_2 > 0$ 内，外点罚函数为： $$P(x_1, x_2, M) = x_1^2 + x_2^2 + M(2 - x_1 - x_2)^2$$ 令一阶偏导数为 $0$： $$\begin{cases} \frac{\partial P}{\partial x_1} = 2x_1 - 2M(2 - x_1 - x_2) = 0 \\[4pt] \frac{\partial P}{\partial x_2} = 2x_2 - 2M(2 - x_1 - x_2) = 0 \end{cases}$$ 两式相减得 $x_1 = x_2$。代入第1式： $$x_1 - M(2 - 2x_1) = 0 \implies (1 + 2M)x_1 = 2M$$ 解得外点序列极小点： $$x_1^*(M) = \frac{2M}{2M + 1}, \quad x_2^*(M) = \frac{2M}{2M + 1}$$ （验证：$x_1^*(M) + x_2^*(M) = \frac{4M}{2M+1} < 2$，确实严格位于可行域外部 $g > 0$，并随 $M$ 增大从外部逼近边界 $x_1 + x_2 = 2$。）
第3步（令 $M \to +\infty$ 求极限）：
$$x_1^* = \lim_{M \to +\infty} \frac{2M}{2M + 1} = 1, \quad x_2^* = \lim_{M \to +\infty} \frac{2M}{2M + 1} = 1$$
结论：通过 SUMT 外点法从可行域外部逼近，求得原问题最优解为 $x^* = (1, 1)^T$，极小值 $f(x^*) = 2$。
三、SUMT 内点法（序列无约束极小化 —— 内点障碍函数法）

【核心原理与标准做题步骤】

内点法 / 障碍函数法（Interior Point / Barrier Method）仅适用于含不等式约束的问题 $\min f(x) \quad \text{s.t.} \; g_i(x) \le 0$（要求严格内点集 $S^0 = \{x \mid g_i(x) < 0\} \neq \varnothing$）。它在可行域边界上筑起一道无限高的“势垒墙”，使迭代点始终保持在可行域严格内部逼近极小点：

  1. 构造内点障碍函数：取障碍因子（罚因子）$r_k > 0$（递减序列 $r_1 > r_2 > \dots \to 0^+$），常用的两种障碍函数形式为：
    • 倒数障碍函数（最常考）： $$B(x, r_k) = f(x) - r_k \sum_{i=1}^m \frac{1}{g_i(x)} \quad \left(\text{若约束写为 } g_i(x) \ge 0\text{，则为 } + r_k \sum \frac{1}{g_i(x)}\right)$$
    • 对数障碍函数： $$B(x, r_k) = f(x) - r_k \sum_{i=1}^m \ln\left[-g_i(x)\right] \quad \left(\text{若约束写为 } g_i(x) \ge 0\text{，则为 } - r_k \sum \ln g_i(x)\right)$$
  2. 在严格可行域内部求驻点 $x^*(r_k)$：令 $\nabla_x B(x, r_k) = 0$，解出满足 $g_i(x) < 0$（严格内点）的极小点 $x^*(r_k)$。
  3. 求极限得最优解：令障碍因子缩减至零（$r_k \to 0^+$），计算： $$x^* = \lim_{r_k \to 0^+} x^*(r_k)$$
例题 3.1（倒数障碍函数的 SUMT 内点法求解）
用 SUMT 内点法（采用倒数障碍函数）求解如下不等式约束极值问题： $$\min f(x) = x^2 - 2x$$ $$\text{s.t.} \quad x \ge 2$$
【详细解题步骤】
第1步（确定严格内点域并构造倒数障碍函数）：
不等式约束为 $x - 2 \ge 0$（即标准形式 $g(x) = 2 - x \le 0$），严格可行域内部为 $x > 2$。
取障碍因子 $r > 0$，在 $x > 2$ 内构造倒数障碍函数： $$B(x, r) = x^2 - 2x + \frac{r}{x - 2}$$
第2步（为了简化代数求解，也可对等效线性项或直接求导；这里展示标准求导与极点提取）：
对 $B(x, r)$ 关于 $x$ 求一阶导数并令其等于 $0$： $$\frac{\partial B(x, r)}{\partial x} = 2x - 2 - \frac{r}{(x - 2)^2} = 0$$ 移项整理得： $$2(x - 1)(x - 2)^2 = r \implies (x - 2)^2 = \frac{r}{2(x - 1)}$$ 因为点位于严格可行域内部 $x > 2$（故 $x - 2 > 0$ 且 $x - 1 > 1 > 0$），两边开平方得： $$x^*(r) = 2 + \sqrt{\frac{r}{2\left(x^*(r) - 1\right)}} > 2$$ （可见对任意 $r > 0$，迭代点 $x^*(r)$ 恒大于 $2$，始终处于可行域的严格内部！）
第3步（令障碍因子 $r \to 0^+$ 求极限）：
当 $r \to 0^+$ 时，右侧根号项 $\sqrt{\frac{r}{2(x^*(r) - 1)}} \to 0$，两边取极限得： $$x^* = \lim_{r \to 0^+} x^*(r) = 2 + 0 = 2$$
结论：内点序列 $x^*(r)$ 从可行域内部（$x > 2$ 一侧）随 $r \to 0^+$ 收敛到边界最优解 $x^* = 2$，极小值 $f(2) = 2^2 - 2(2) = 0$。
例题 3.2（二元函数的对数与倒数障碍函数内点法完整求解）
用 SUMT 内点法求解二元有约束优化问题（分别用对数障碍函数和倒数障碍函数推导）： $$\min f(x_1, x_2) = x_1 + \frac{1}{2}x_2^2$$ $$\text{s.t.} \quad x_1 \ge 1$$
【详细解题步骤】
方法 A（采用对数障碍函数）：
严格内点域为 $x_1 - 1 > 0$。取障碍因子 $r > 0$，构造对数障碍函数： $$B_1(x_1, x_2, r) = x_1 + \frac{1}{2}x_2^2 - r \ln(x_1 - 1)$$ 令一阶偏导数为 $0$： $$\begin{cases} \frac{\partial B_1}{\partial x_1} = 1 - \frac{r}{x_1 - 1} = 0 \\[4pt] \frac{\partial B_1}{\partial x_2} = x_2 = 0 \end{cases}$$ 因 $x_1 > 1$，直接解出含 $r$ 的显式内点解析解： $$x_1^*(r) = 1 + r, \quad x_2^*(r) = 0$$
方法 B（采用倒数障碍函数）：
在严格内点域 $x_1 - 1 > 0$ 内，构造倒数障碍函数： $$B_2(x_1, x_2, r) = x_1 + \frac{1}{2}x_2^2 + \frac{r}{x_1 - 1}$$ 令一阶偏导数为 $0$： $$\begin{cases} \frac{\partial B_2}{\partial x_1} = 1 - \frac{r}{(x_1 - 1)^2} = 0 \\[4pt] \frac{\partial B_2}{\partial x_2} = x_2 = 0 \end{cases}$$ 因要求点在严格可行域内部（$x_1 - 1 > 0$），舍去负根 $1 - \sqrt{r}$，保留正根得显式内点解： $$x_1^*(r) = 1 + \sqrt{r}, \quad x_2^*(r) = 0$$
第3步（令 $r \to 0^+$ 取极限求原问题极小点）：
无论采用对数障碍函数还是倒数障碍函数，令 $r \to 0^+$ 均有： $$x_1^* = \lim_{r \to 0^+} (1 + r) = \lim_{r \to 0^+} (1 + \sqrt{r}) = 1, \quad x_2^* = \lim_{r \to 0^+} 0 = 0$$
结论：内点解为 $x^*(r) = (1+r, 0)^T$（对数型）或 $(1+\sqrt{r}, 0)^T$（倒数型），当 $r \to 0^+$ 时从可行域内部收敛到精确极小点 $x^* = (1, 0)^T$，极小值 $f(x^*) = 1$。
