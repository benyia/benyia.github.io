一、K-T 条件（库恩-塔克条件 / Kuhn-Tucker Conditions）

【核心原理与标准做题步骤（教材 $g_i(x) \ge 0$ 形式）】

考虑教材标准形式的有约束最优化问题： $$\min f(x) \quad \text{s.t.} \quad g_i(x) \ge 0 \; (i=1,\dots,m), \quad h_j(x) = 0 \; (j=1,\dots,l)$$ 求解 K-T 点（极小值的一阶必要条件，当问题为凸规划时也是充要条件）的标准步骤如下：

  1. 化为标准形式：将所有不等式约束统一移项整理为 $g_i(x) \ge 0$，等式约束整理为 $h_j(x) = 0$。
  2. 构造拉格朗日函数：引入拉格朗日乘子 $\lambda_i \ge 0$ 和 $\mu_j \in \mathbb{R}$，构造拉格朗日函数： $$L(x, \lambda, \mu) = f(x) - \sum_{i=1}^m \lambda_i g_i(x) - \sum_{j=1}^l \mu_j h_j(x)$$
  3. 列出 K-T 条件方程组：
    • 一阶驻点条件：$\nabla_x L(x, \lambda, \mu) = \nabla f(x) - \sum_{i=1}^m \lambda_i \nabla g_i(x) - \sum_{j=1}^l \mu_j \nabla h_j(x) = 0$
    • 互补松弛条件：$\lambda_i g_i(x) = 0 \quad (i=1,2,\dots,m)$
    • 原始可行性条件：$g_i(x) \ge 0, \quad h_j(x) = 0$
    • 乘子非负条件：$\lambda_i \ge 0 \quad (i=1,2,\dots,m)$
  4. 分情况讨论求解：根据互补松弛条件 $\lambda_i g_i(x) = 0$，按乘子 $\lambda_i = 0$（非起作用约束，内部点）或 $g_i(x) = 0$（起作用约束，边界点）分类讨论，并逐一检验求得的解是否同时满足原始可行性 $g_i(x) \ge 0$ 和乘子非负性 $\lambda_i \ge 0$。
例题 1.1（单个不等式约束的 K-T 点求解）
利用 K-T 条件求解非线性规划问题： $$\min f(x_1, x_2) = (x_1 - 2)^2 + (x_2 - 1)^2$$ $$\text{s.t.} \quad x_1 + x_2 \le 1$$
【详细解题步骤】
第 1 步：化为标准形式 $g(x) \ge 0$ 并构造拉格朗日函数
将不等式约束写为教材标准形式： $$g(x_1, x_2) = 1 - x_1 - x_2 \ge 0$$ 引入拉格朗日乘子 $\lambda \ge 0$，构造拉格朗日函数： $$L(x_1, x_2, \lambda) = (x_1 - 2)^2 + (x_2 - 1)^2 - \lambda(1 - x_1 - x_2)$$
第 2 步：写出 K-T 条件方程组
对 $x_1, x_2$ 分别求偏导并结合约束条件，列出 K-T 方程组： $$\begin{cases} \dfrac{\partial L}{\partial x_1} = 2(x_1 - 2) + \lambda = 0 & (1) \\[10pt] \dfrac{\partial L}{\partial x_2} = 2(x_2 - 1) + \lambda = 0 & (2) \\[10pt] \lambda(1 - x_1 - x_2) = 0 & (3) \\[8pt] 1 - x_1 - x_2 \ge 0 & (4) \\[8pt] \lambda \ge 0 & (5) \end{cases}$$
第 3 步：按互补松弛条件 (3) 分情况讨论
  • 情况一：令 $\lambda = 0$（约束不起作用，内部点）
    代入 (1)、(2) 两式得：$2(x_1 - 2) = 0 \implies x_1 = 2$；$2(x_2 - 1) = 0 \implies x_2 = 1$。
    检验可行性条件 (4)：$g(2, 1) = 1 - 2 - 1 = -2 < 0$，不满足 $1 - x_1 - x_2 \ge 0$，故舍去！
  • 情况二：令 $1 - x_1 - x_2 = 0$（约束起作用，边界点）
    由 (1) 和 (2) 解出用 $\lambda$ 表示的坐标：$x_1 = 2 - \dfrac{\lambda}{2}$，$x_2 = 1 - \dfrac{\lambda}{2}$。
    将其代入边界方程 $1 - x_1 - x_2 = 0$ 得： $$1 - \left(2 - \frac{\lambda}{2}\right) - \left(1 - \frac{\lambda}{2}\right) = 0 \implies \lambda - 2 = 0 \implies \lambda = 2$$ 检验乘子非负条件 (5)：$\lambda = 2 \ge 0$，满足要求。
    回代求得极值点坐标：$x_1 = 2 - \dfrac{2}{2} = 1$，$x_2 = 1 - \dfrac{2}{2} = 0$。
结论：该问题的唯一 K-T 点为 $x^* = (1, 0)^T$，对应乘子 $\lambda^* = 2$。因目标函数为严格凸函数且可行域为凸集，故 $x^* = (1, 0)^T$ 即为全局极小点，极小值 $f(x^*) = (1-2)^2 + (0-1)^2 = 2$。
例题 1.2（含两个不等式约束的 K-T 条件求解）
利用 K-T 条件求解有约束极值问题： $$\min f(x_1, x_2) = x_1^2 + x_2^2 - 4x_1 - 4x_2$$ $$\text{s.t.} \quad \begin{cases} x_1 + x_2 \le 2 \\ x_1 \ge 0 \end{cases}$$
【详细解题步骤】
第 1 步：化为标准形式 $g_i(x) \ge 0$ 并写出 K-T 条件
将两个不等式约束统一化为 $g_i(x) \ge 0$ 标准形式： $$g_1(x) = 2 - x_1 - x_2 \ge 0, \qquad g_2(x) = x_1 \ge 0$$ 构造拉格朗日函数： $$L(x_1, x_2, \lambda_1, \lambda_2) = x_1^2 + x_2^2 - 4x_1 - 4x_2 - \lambda_1(2 - x_1 - x_2) - \lambda_2 x_1$$ 列出 K-T 条件方程组： $$\begin{cases} \dfrac{\partial L}{\partial x_1} = 2x_1 - 4 + \lambda_1 - \lambda_2 = 0 & (1) \\[10pt] \dfrac{\partial L}{\partial x_2} = 2x_2 - 4 + \lambda_1 = 0 & (2) \\[10pt] \lambda_1(2 - x_1 - x_2) = 0, \quad \lambda_2 x_1 = 0 & (3) \\[8pt] 2 - x_1 - x_2 \ge 0, \quad x_1 \ge 0 & (4) \\[8pt] \lambda_1 \ge 0, \quad \lambda_2 \ge 0 & (5) \end{cases}$$
第 2 步：对互补松弛条件进行 4 种组合讨论
  • 情形 1（$\lambda_1 = 0, \; \lambda_2 = 0$，两约束均不起作用）：
    由 (1)、(2) 得 $x_1 = 2, \; x_2 = 2$。代入 $g_1(x)$ 得 $2 - 2 - 2 = -2 < 0$，违背可行性条件 (4)，舍去。
  • 情形 2（$\lambda_1 > 0, \; \lambda_2 = 0$，仅第 1 个约束起作用 $2 - x_1 - x_2 = 0$）：
    由 (1)、(2) 知 $2x_1 - 4 + \lambda_1 = 0$ 且 $2x_2 - 4 + \lambda_1 = 0$，故 $x_1 = x_2$。
    代入 $2 - x_1 - x_2 = 0$ 解得：$x_1 = 1, \; x_2 = 1$。
    回代 (2) 式求乘子：$\lambda_1 = 4 - 2(1) = 2 > 0$（满足 $\lambda_1 \ge 0$）。
    检验第 2 个约束：$g_2(x) = x_1 = 1 \ge 0$ 成立。所有 K-T 条件全部满足！
  • 情形 3（$\lambda_1 = 0, \; \lambda_2 > 0$，仅第 2 个约束起作用 $x_1 = 0$）：
    将 $\lambda_1 = 0, \; x_1 = 0$ 代入 (1) 式得：$-4 - \lambda_2 = 0 \implies \lambda_2 = -4 < 0$，违背乘子非负条件 $\lambda_2 \ge 0$，舍去。
  • 情形 4（$\lambda_1 > 0, \; \lambda_2 > 0$，两个约束同时起作用 $x_1 = 0$ 且 $2 - x_1 - x_2 = 0$）：
    解得 $x_1 = 0, \; x_2 = 2$。代入 (2) 式得 $\lambda_1 = 4 - 2(2) = 0$，再代入 (1) 式得 $\lambda_2 = -4 < 0$，违背乘子非负条件，舍去。
结论：唯一 K-T 点为 $x^* = (1, 1)^T$，对应拉格朗日乘子 $\lambda^* = (2, 0)^T$，全局极小值为 $f(x^*) = 1^2 + 1^2 - 4(1) - 4(1) = -6$。
二、SUMT 外点法（序列无约束极小化 —— 外点罚函数法）

【核心原理与标准做题步骤（教材 $g_i(x) \ge 0$ 形式）】

外点罚函数法（Exterior Penalty Method）将违反约束的程度转化为惩罚项加到目标函数上，从而把有约束优化转化为一系列无约束优化问题。迭代点序列通常从可行域外部逐渐逼近最优解（可同时处理等式约束与不等式约束）：

  1. 构造外点罚函数（增广目标函数）：对于标准问题 $\min f(x) \quad \text{s.t.} \; g_i(x) \ge 0, \; h_j(x) = 0$，取递增的正罚因子序列 $M_k > 0$（$M_1 < M_2 < \dots \to +\infty$），构造外点罚函数： $$P(x, M_k) = f(x) + M_k \sum_{i=1}^m \left[\min\{0, g_i(x)\}\right]^2 + M_k \sum_{j=1}^l \left[h_j(x)\right]^2$$ （注：当迭代点位于不可行域外部时，违反约束意味着 $g_i(x) < 0$，此时 $\min\{0, g_i(x)\} = g_i(x)$，惩罚项直接写为 $M_k \left[g_i(x)\right]^2$。）
  2. 求解无约束极小点 $x^*(M_k)$：对 $P(x, M_k)$ 求关于 $x$ 的一阶梯度并令其为 $0$： $$\nabla_x P(x, M_k) = 0$$ 解出含罚因子 $M_k$ 的解析驻点 $x^*(M_k)$。
  3. 求极限得原问题最优解：令罚因子 $M_k \to +\infty$，计算极限： $$x^* = \lim_{M_k \to +\infty} x^*(M_k)$$
例题 2.1（等式约束问题的 SUMT 外点法求解）
用 SUMT 外点罚函数法求解等式约束优化问题： $$\min f(x_1, x_2) = x_1^2 + 2x_2^2$$ $$\text{s.t.} \quad x_1 + x_2 = 1$$
【详细解题步骤】
第 1 步：构造外点罚函数 $P(x_1, x_2, M)$
将等式约束写为标准形式 $h(x_1, x_2) = x_1 + x_2 - 1 = 0$。引入罚因子 $M > 0$，构造增广目标函数： $$P(x_1, x_2, M) = x_1^2 + 2x_2^2 + M(x_1 + x_2 - 1)^2$$
第 2 步：求解无约束极值必要条件 $\nabla_x P = 0$
分别对 $x_1, x_2$ 求一阶偏导并令其等于 $0$： $$\begin{cases} \dfrac{\partial P}{\partial x_1} = 2x_1 + 2M(x_1 + x_2 - 1) = 0 & (1) \\[10pt] \dfrac{\partial P}{\partial x_2} = 4x_2 + 2M(x_1 + x_2 - 1) = 0 & (2) \end{cases}$$ 用 (1) 式减去 (2) 式消去含罚因子 $M$ 的项： $$2x_1 - 4x_2 = 0 \implies x_1 = 2x_2$$ 将 $x_1 = 2x_2$ 代回 (2) 式： $$4x_2 + 2M(2x_2 + x_2 - 1) = 0 \implies (2 + 3M)x_2 = M$$ 解得关于罚因子 $M$ 的无约束极小点 $x^*(M)$： $$x_1^*(M) = \frac{2M}{3M + 2}, \qquad x_2^*(M) = \frac{M}{3M + 2}$$ （验证：对任意有限 $M > 0$，$x_1^*(M) + x_2^*(M) = \dfrac{3M}{3M+2} < 1$，说明迭代点严格位于可行集外部。）
第 3 步：令 $M \to +\infty$ 取极限求最优解
$$x_1^* = \lim_{M \to +\infty} \frac{2M}{3M + 2} = \lim_{M \to +\infty} \frac{2}{3 + \frac{2}{M}} = \frac{2}{3}$$ $$x_2^* = \lim_{M \to +\infty} \frac{M}{3M + 2} = \lim_{M \to +\infty} \frac{1}{3 + \frac{2}{M}} = \frac{1}{3}$$
结论：原问题的最优解（极小点）为 $x^* = \left(\dfrac{2}{3}, \dfrac{1}{3}\right)^T$，极小值为 $f(x^*) = \left(\dfrac{2}{3}\right)^2 + 2\left(\dfrac{1}{3}\right)^2 = \dfrac{2}{3}$。
例题 2.2（不等式约束问题的 SUMT 外点法求解）
用 SUMT 外点罚函数法求解不等式约束优化问题： $$\min f(x_1, x_2) = x_1^2 + x_2^2$$ $$\text{s.t.} \quad x_1 + x_2 \ge 2$$
【详细解题步骤】
第 1 步：化为标准形式 $g(x) \ge 0$ 并判断迭代点区域
将不等式约束写为教材标准形式： $$g(x_1, x_2) = x_1 + x_2 - 2 \ge 0$$ 原目标函数 $f(x_1, x_2) = x_1^2 + x_2^2$ 的无约束极小点为 $(0, 0)^T$，代入约束得 $g(0, 0) = -2 < 0$，位于可行域外部。因此外点法的迭代点必落在不可行域 $g(x_1, x_2) < 0$（即 $x_1 + x_2 - 2 < 0$）内，此时 $\min\{0, g(x)\} = x_1 + x_2 - 2$。
第 2 步：构造外点罚函数并求无约束极小点
在不可行域 $x_1 + x_2 - 2 < 0$ 内，构造外点罚函数： $$P(x_1, x_2, M) = x_1^2 + x_2^2 + M(x_1 + x_2 - 2)^2$$ 令一阶偏导数为 $0$： $$\begin{cases} \dfrac{\partial P}{\partial x_1} = 2x_1 + 2M(x_1 + x_2 - 2) = 0 & (1) \\[10pt] \dfrac{\partial P}{\partial x_2} = 2x_2 + 2M(x_1 + x_2 - 2) = 0 & (2) \end{cases}$$ 两式相减得 $x_1 = x_2$。代入 (1) 式整理得： $$x_1 + M(2x_1 - 2) = 0 \implies (1 + 2M)x_1 = 2M$$ 解得外点序列极小点： $$x_1^*(M) = \frac{2M}{2M + 1}, \qquad x_2^*(M) = \frac{2M}{2M + 1}$$ （验证：对任意 $M > 0$，有 $g(x^*(M)) = \dfrac{4M}{2M+1} - 2 = \dfrac{-2}{2M+1} < 0$，确实严格位于可行域外部，并随 $M \to +\infty$ 从外部逼近边界 $x_1 + x_2 - 2 = 0$。）
第 3 步：令 $M \to +\infty$ 求极限
$$x_1^* = \lim_{M \to +\infty} \frac{2M}{2M + 1} = 1, \qquad x_2^* = \lim_{M \to +\infty} \frac{2M}{2M + 1} = 1$$
结论：通过 SUMT 外点法从可行域外部（$g(x) < 0$ 区域）逼近，求得原问题最优解为 $x^* = (1, 1)^T$，极小值 $f(x^*) = 2$。
三、SUMT 内点法（序列无约束极小化 —— 内点障碍函数法）

【核心原理与标准做题步骤（教材 $g_i(x) \ge 0$ 形式）】

内点法 / 障碍函数法（Interior Point / Barrier Method）仅适用于含不等式约束的优化问题： $$\min f(x) \quad \text{s.t.} \quad g_i(x) \ge 0 \; (i=1,\dots,m)$$ 要求可行域的严格内部非空，即严格内点集 $S^0 = \{x \mid g_i(x) > 0, \; i=1,\dots,m\} \neq \varnothing$。它在可行域边界 $g_i(x) = 0$ 上筑起一道无限高的“势垒墙”，迫使迭代点序列始终保持在可行域严格内部（$g_i(x) > 0$）逼近最优解：

  1. 构造内点障碍函数（增广目标函数）：取递减的正障碍因子序列 $r_k > 0$（$r_1 > r_2 > \dots \to 0^+$），教材常用的两种标准障碍函数形式为：
    • 倒数障碍函数（最常考）： $$B(x, r_k) = f(x) + r_k \sum_{i=1}^m \frac{1}{g_i(x)}$$
    • 对数障碍函数： $$B(x, r_k) = f(x) - r_k \sum_{i=1}^m \ln\left[g_i(x)\right]$$
  2. 在严格可行域内部求无约束极小点 $x^*(r_k)$：令梯度 $\nabla_x B(x, r_k) = 0$，求解并筛选出满足严格内点条件 $g_i(x) > 0$ 的驻点 $x^*(r_k)$。
  3. 求极限得原问题最优解：令障碍因子缩减至零（$r_k \to 0^+$），计算极限： $$x^* = \lim_{r_k \to 0^+} x^*(r_k)$$
例题 3.1（倒数障碍函数的 SUMT 内点法求解）
用 SUMT 内点法（采用倒数障碍函数）求解如下不等式约束极值问题： $$\min f(x) = x^2 - 2x$$ $$\text{s.t.} \quad x \ge 2$$
【详细解题步骤】
第 1 步：写出标准形式 $g(x) \ge 0$ 并构造倒数障碍函数
将不等式约束化为教材标准形式： $$g(x) = x - 2 \ge 0$$ 因此严格内点域为 $S^0 = \{x \mid x - 2 > 0\} = \{x \mid x > 2\}$。
取障碍因子 $r > 0$，在严格内点域 $x > 2$ 内构造倒数障碍函数： $$B(x, r) = f(x) + \frac{r}{g(x)} = x^2 - 2x + \frac{r}{x - 2}$$
第 2 步：在严格内点域 $x > 2$ 内求解驻点条件 $\nabla_x B(x, r) = 0$
对 $B(x, r)$ 关于 $x$ 求一阶导数并令其等于 $0$： $$\frac{\mathrm{d}B(x, r)}{\mathrm{d}x} = 2x - 2 - \frac{r}{(x - 2)^2} = 0$$ 移项整理得： $$2(x - 1)(x - 2)^2 = r \implies (x - 2)^2 = \frac{r}{2(x - 1)}$$ 因为内点法的迭代点必须位于严格可行域内部 $x > 2$（故 $x - 2 > 0$ 且 $x - 1 > 1 > 0$），两边开平方取正根得： $$x^*(r) = 2 + \sqrt{\frac{r}{2\left(x^*(r) - 1\right)}} > 2$$ （可见对任意 $r > 0$，极小点 $x^*(r)$ 恒满足 $g(x^*(r)) = x^*(r) - 2 > 0$，始终处于可行域的严格内部！）
第 3 步：令障碍因子 $r \to 0^+$ 求极限
当 $r \to 0^+$ 时，右侧根号项 $\sqrt{\dfrac{r}{2(x^*(r) - 1)}} \to 0$，两边取极限得： $$x^* = \lim_{r \to 0^+} x^*(r) = 2 + 0 = 2$$
结论：内点序列 $x^*(r)$ 从严格可行域内部（$x - 2 > 0$ 一侧）随 $r \to 0^+$ 收敛到边界最优解 $x^* = 2$，极小值 $f(2) = 2^2 - 2(2) = 0$。
例题 3.2（二元函数的对数与倒数障碍函数内点法完整求解）
用 SUMT 内点法求解二元有约束优化问题（分别用对数障碍函数和倒数障碍函数推导）： $$\min f(x_1, x_2) = x_1 + \frac{1}{2}x_2^2$$ $$\text{s.t.} \quad x_1 \ge 1$$
【详细解题步骤】
方法 A：采用对数障碍函数 $B_1(x, r) = f(x) - r \ln[g(x)]$
将不等式约束写为标准形式 $g(x_1, x_2) = x_1 - 1 \ge 0$，严格内点域为 $x_1 - 1 > 0$。
取障碍因子 $r > 0$，构造对数障碍函数： $$B_1(x_1, x_2, r) = x_1 + \frac{1}{2}x_2^2 - r \ln(x_1 - 1)$$ 令一阶偏导数为 $0$： $$\begin{cases} \dfrac{\partial B_1}{\partial x_1} = 1 - \dfrac{r}{x_1 - 1} = 0 \\[10pt] \dfrac{\partial B_1}{\partial x_2} = x_2 = 0 \end{cases}$$ 因 $x_1 - 1 > 0$，直接解出含 $r$ 的显式内点解析解： $$x_1^*(r) = 1 + r, \qquad x_2^*(r) = 0$$
方法 B：采用倒数障碍函数 $B_2(x, r) = f(x) + \dfrac{r}{g(x)}$
在严格内点域 $g(x_1, x_2) = x_1 - 1 > 0$ 内，构造倒数障碍函数： $$B_2(x_1, x_2, r) = x_1 + \frac{1}{2}x_2^2 + \frac{r}{x_1 - 1}$$ 令一阶偏导数为 $0$： $$\begin{cases} \dfrac{\partial B_2}{\partial x_1} = 1 - \dfrac{r}{(x_1 - 1)^2} = 0 \\[10pt] \dfrac{\partial B_2}{\partial x_2} = x_2 = 0 \end{cases}$$ 因要求点位于严格可行域内部（$x_1 - 1 > 0$），舍去不合题意的负根 $1 - \sqrt{r}$，保留正根得显式内点解： $$x_1^*(r) = 1 + \sqrt{r}, \qquad x_2^*(r) = 0$$
第 3 步：令 $r \to 0^+$ 取极限求原问题极小点
无论采用对数障碍函数还是倒数障碍函数，令 $r \to 0^+$ 均有： $$x_1^* = \lim_{r \to 0^+} (1 + r) = \lim_{r \to 0^+} (1 + \sqrt{r}) = 1, \qquad x_2^* = \lim_{r \to 0^+} 0 = 0$$
结论：内点解为 $x^*(r) = (1+r, 0)^T$（对数型）或 $(1+\sqrt{r}, 0)^T$（倒数型），当 $r \to 0^+$ 时从严格可行域内部（$g(x) > 0$）收敛到精确极小点 $x^* = (1, 0)^T$，极小值 $f(x^*) = 1$。
