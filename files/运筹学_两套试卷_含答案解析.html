一线性规划图解法与几何寻优

8 分

用图解法求解下列线性规划问题，在直角坐标系中标出可行域、等值线移动方向及全部极点（顶点），并求最优解 $x^*$ 与最优目标值 $z^*$：

$$\begin{aligned} \max \quad & z = x_1 + 2x_2 \\ \text{s.t.} \quad & \begin{cases} x_1 + x_2 \le 4 \\ x_1 + 3x_2 \le 6 \\ x_1, \, x_2 \ge 0 \end{cases} \end{aligned}$$
答案与详解
步骤 1 绘制约束边界直线并确定可行域顶点

将各不等式约束改写为边界直线方程，求其与坐标轴的交点及两直线的交点：

  • 直线 $L_1: x_1 + x_2 = 4$ 过点 $A(4, 0)$ 与 $(0, 4)$，取左下侧半平面 $x_1 + x_2 \le 4$；
  • 直线 $L_2: x_1 + 3x_2 = 6$ 过点 $(6, 0)$ 与 $B(0, 2)$，取左下侧半平面 $x_1 + 3x_2 \le 6$；
  • 结合非负象限 $x_1 \ge 0, \, x_2 \ge 0$，联立 $L_1$ 与 $L_2$ 求交点 $C$：
$$\begin{cases} x_1 + x_2 = 4 \\ x_1 + 3x_2 = 6 \end{cases} \quad \Longrightarrow \quad 2x_2 = 2 \implies x_2 = 1, \quad x_1 = 4 - 1 = 3 \quad \Longrightarrow \quad C(3, 1)$$

故可行域 $D$ 是以 $O(0, 0)$、$A(4, 0)$、$C(3, 1)$、$B(0, 2)$ 为顶点的有界凸四边形区域。

步骤 2 移动目标函数等值线并对比全部极点目标值

目标函数等值线为 $x_1 + 2x_2 = z$，其斜率为 $k = -\dfrac{1}{2}$，介于直线 $L_1$ 的斜率 $k_1 = -1$ 与直线 $L_2$ 的斜率 $k_2 = -\dfrac{1}{3}$ 之间（即 $-1 < -\dfrac{1}{2} < -\dfrac{1}{3}$）。因此沿法向量 $\nabla z = (1, 2)^T$ 向右上方平移时，必在唯一交点 $C(3, 1)$ 处取得最大值：

四对偶问题构造、互补松弛定理与影子价格分析

10 分

沿用第一题的原线性规划问题：

$$\max \; z = x_1 + 2x_2 \quad \text{s.t.} \quad \begin{cases} x_1 + x_2 \le 4 \\ x_1 + 3x_2 \le 6 \\ x_1, \, x_2 \ge 0 \end{cases}$$

（1）写出其对偶问题（Dual Problem）；（2）已知原问题最优解为 $x^* = (3, 1)^T$，利用互补松弛定理求出对偶问题的最优解 $y^*$；（3）解释两种资源的影子价格含义，并求出在最优基保持不变的前提下，第 1 种资源右端项 $b_1$ 的允许变化范围及最优值函数 $z(b_1)$。

答案与详解
步骤 1 构造对偶线性规划问题

设第 1、2 条资源约束对应的对偶变量（影子价格）分别为 $y_1, y_2$。由对称形式对偶规则（$\max \leftrightarrow \min$，“$\le$”约束配 $y_i \ge 0$，$x_j \ge 0$ 配“$\ge$”对偶约束），写出对偶问题：

$$\begin{aligned} \min \quad & w = 4y_1 + 6y_2 \\ \text{s.t.} \quad & \begin{cases} y_1 + y_2 \ge 1 \\ y_1 + 3y_2 \ge 2 \\ y_1, \, y_2 \ge 0 \end{cases} \end{aligned}$$
步骤 2 应用互补松弛定理求对偶最优解 $y^*$

记原问题松弛变量为 $s_1 = 4 - x_1 - x_2, \, s_2 = 6 - x_1 - 3x_2$；记对偶问题剩余变量为 $e_1 = y_1 + y_2 - 1, \, e_2 = y_1 + 3y_2 - 2$。互补松弛定理要求：

$$\begin{cases} x_j^* e_j^* = 0 & (j = 1, 2) \\ y_i^* s_i^* = 0 & (i = 1, 2) \end{cases}$$

因为原问题最优解 $x_1^* = 3 > 0$ 且 $x_2^* = 1 > 0$，由 $x_1^* e_1^* = 0$ 与 $x_2^* e_2^* = 0$ 可知，两条对偶约束必须严格取等号（$e_1^* = e_2^* = 0$）：

$$\begin{cases} y_1^* + y_2^* = 1 \\ y_1^* + 3y_2^* = 2 \end{cases} \quad \Longrightarrow \quad \begin{cases} y_1^* = \dfrac{1}{2} \\[6pt] y_2^* = \dfrac{1}{2} \end{cases}$$

检验非负性与强对偶定理：$y_1^* = \dfrac{1}{2} \ge 0, \, y_2^* = \dfrac{1}{2} \ge 0$，且 $w^* = 4\times\dfrac{1}{2} + 6\times\dfrac{1}{2} = 5 = z^*$。

步骤 3 影子价格经济解释与右端项 $b_1$ 的灵敏度范围

设第 1 种资源右端项为 $b_1 = 4 + \Delta b_1$（固定 $b_2 = 6$）。当最优基 $X_B = (x_1, x_2)^T$ 保持不变时，联立紧约束方程组：

$$\begin{cases} x_1 + x_2 = b_1 \\ x_1 + 3x_2 = 6 \end{cases} \quad \Longrightarrow \quad \begin{cases} x_1(b_1) = \dfrac{3b_1 - 6}{2} \ge 0 \\[6pt] x_2(b_1) = \dfrac{6 - b_1}{2} \ge 0 \end{cases} \quad \Longrightarrow \quad \mathbf{2 \le b_1 \le 6} \; (\text{即 } -2 \le \Delta b_1 \le 2)$$

在该稳定区间 $b_1 \in [2, 6]$ 内，最优目标值关于 $b_1$ 的线性函数为：

$$z^*(b_1) = x_1(b_1) + 2x_2(b_1) = \frac{3b_1 - 6}{2} + (6 - b_1) = \frac{1}{2}b_1 + 3 = 5 + \frac{1}{2}\Delta b_1, \qquad \frac{\partial z^*}{\partial b_1} = y_1^* = \frac{1}{2}$$
结论：对偶最优解为 $y^* = \left(\dfrac{1}{2}, \dfrac{1}{2}\right)^T$；两种资源的影子价格均为 $\dfrac{1}{2}$。在允许范围 $b_1 \in [2, 6]$ 内，资源 1 每增加 1 个单位，最大目标值精确增加 $\dfrac{1}{2}$ 个单位。

$$\nabla F(x) = \begin{pmatrix} 4x_1 + x_2 - 2 \\ x_1 + 2x_2 - 1 \end{pmatrix}, \qquad H = \nabla^2 F(x) = \begin{pmatrix} 4 & 1 \\ 1 & 2 \end{pmatrix}$$

$$g_1 = \nabla f\left(\frac{4}{3}, \frac{7}{3}\right) = \begin{pmatrix} -\frac{4}{3} \\[4pt] \frac{4}{3} \end{pmatrix}, \qquad \beta_0 = \frac{\|g_1\|^2}{\|g_0\|^2} = \frac{32/9}{32} = \frac{1}{9}$$
$$p^{(1)} = -g_1 + \beta_0 p^{(0)} = \begin{pmatrix} \frac{4}{3} \\[4pt] -\frac{4}{3} \end{pmatrix} + \frac{1}{9}\begin{pmatrix} 4 \\ 4 \end{pmatrix} = \begin{pmatrix} \frac{16}{9} \\[4pt] -\frac{8}{9} \end{pmatrix}$$

十二约束优化：外点罚函数法与内点障碍函数法

考虑一维约束极小化问题：$\min \; f(x) = (x + 1)^2, \quad \text{s.t.} \; x \ge 0$。

（2）构造对数内点障碍函数 $B(x, \mu)$，求障碍因子 $\mu = \dfrac{1}{2}$ 时的严格内点极小点 $x(\mu)$，并分析当 $\mu \to 0^+$ 时的极限。

答案与详解
第 (1) 问 外点罚函数法（Exterior Penalty Method）

将约束写为 $g(x) = -x \le 0$，违反量函数为 $[\max(0, -x)]^2$。构造外点罚函数：

$$P(x, \sigma) = (x + 1)^2 + \sigma \big[\max(0, -x)\big]^2 = \begin{cases} (x + 1)^2, & x \ge 0 \\ (x + 1)^2 + \sigma x^2, & x < 0 \end{cases}$$

由于无约束极小点 $x = -1$ 位于不可行域 $x < 0$ 内，对 $x < 0$ 分支求导并令 $P'_x(x, \sigma) = 0$：

$$P'_x(x, \sigma) = 2(x + 1) + 2\sigma x = 0 \quad \Longrightarrow \quad x(\sigma) = -\frac{1}{1 + \sigma} < 0$$

当 $\sigma = 3$ 时，$x(3) = -\dfrac{1}{1 + 3} = \mathbf{-\dfrac{1}{4} = -0.25}$；当罚参数 $\sigma \to +\infty$ 时，$\lim_{\sigma \to +\infty} x(\sigma) = 0^-$，从可行域外部逼近精确最优点 $x^* = 0$。

第 (2) 问 对数内点障碍函数法（Logarithmic Barrier Method）

在严格可行域内部 $x > 0$ 上构造对数障碍函数（或倒数障碍函数）：

$$B(x, \mu) = (x + 1)^2 - \mu \ln x \qquad (x > 0, \; \mu > 0)$$

在 $(0, +\infty)$ 上求导并令 $B'_x(x, \mu) = 0$：

$$B'_x(x, \mu) = 2(x + 1) - \frac{\mu}{x} = 0 \quad \Longleftrightarrow \quad 2x^2 + 2x - \mu = 0 \quad \Longrightarrow \quad x(\mu) = \frac{-1 + \sqrt{1 + 2\mu}}{2} > 0$$

当 $\mu = \dfrac{1}{2}$ 时，$x\left(\dfrac{1}{2}\right) = \mathbf{\dfrac{\sqrt{2} - 1}{2} \approx 0.2071}$；当障碍参数 $\mu \to 0^+$ 时，$\lim_{\mu \to 0^+} x(\mu) = 0^+$，始终保持在可行域内部逼近精确最优点 $x^* = 0$。

结论：外点法在 $\sigma = 3$ 时近似解为 $x = -\dfrac{1}{4}$；内点法在 $\mu = \dfrac{1}{2}$ 时近似解为 $x = \dfrac{\sqrt{2}-1}{2} \approx 0.2071$。当 $\sigma \to +\infty, \, \mu \to 0^+$ 时，两者分别从可行域外侧与内侧收敛于约束最优解 $x^* = 0, \; f^* = 1$。

$$x_1 + \left(0 + \frac{2}{3}\right)x_2 + \left(0 + \frac{1}{3}\right)s = 2 + \frac{1}{3} \quad \Longleftrightarrow \quad \frac{2}{3}x_2 + \frac{1}{3}s - \frac{1}{3} = 2 - x_1 \in \mathbb{Z}$$

因为 $x_2 \ge 0, \, s \ge 0$，左端 $\dfrac{2}{3}x_2 + \dfrac{1}{3}s - \dfrac{1}{3} > -1$；又因为右端 $2 - x_1$ 为整数，一个大于 $-1$ 的整数必定大于或等于 $0$！由此得到标准 Gomory 分数割不等式：

$$\frac{2}{3}x_2 + \frac{1}{3}s \ge \frac{1}{3} \quad \Longleftrightarrow \quad -\frac{2}{3}x_2 - \frac{1}{3}s + s_{\text{cut}} = -\frac{1}{3} \quad (s_{\text{cut}} \ge 0)$$

将原约束关系 $s = 7 - 3x_1 - 2x_2$ 代入上式消去松弛变量 $s$：

$$\frac{2}{3}x_2 + \frac{1}{3}(7 - 3x_1 - 2x_2) \ge \frac{1}{3} \quad \Longrightarrow \quad \frac{7}{3} - x_1 \ge \frac{1}{3} \quad \Longrightarrow \quad \mathbf{x_1 \le 2}$$

$$P(x, \sigma) = (x - 2)^2 + \sigma \big[\max(0, x - 1)\big]^2$$

$$B(x, \mu) = (x - 2)^2 - \mu \ln(1 - x) \qquad (x < 1, \; \mu > 0)$$

$$B'_x(x, \mu) = 2(x - 2) + \frac{\mu}{1 - x} = 0$$
