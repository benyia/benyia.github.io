1第1章 绪论 · 概念速记 5 问 无计算

建议用时：15 分钟 · 只应对简答/填空
  1. 运筹学定义（莫尔斯-金博尔）：为决策机构在对其控制下的业务活动进行决策时，提供以量化为基础的科学方法。
  2. 工作步骤五步走：① 分析问题（明确目标、约束、可控变量）→ ② 建立模型 → ③ 求解 → ④ 解的检验与灵敏度分析 → ⑤ 解的实施。
  3. 数学模型三要素：决策变量、目标函数、约束条件。
  4. 主要分支：数学规划（线性/非线性/整数/动态/目标规划）、图与网络、排队论、存储论、对策论、决策论等。
  5. 解的类型：可行解（满足全部约束）、最优解（目标最优）、满意解（次优但可接受）。

2第2章 线性规划 必考

建议用时：2 小时 · 本章是全课程的地基，单纯形法必须动手算
必背套路：
① 建模：设变量 → 写目标 → 写约束（资源限量 ≤、需求 ≥）→ 非负。
② 标准化：≤ 加松弛变量；≥ 减剩余变量；= 加人工变量；min 化 max 加负号。
③ 单纯形法五循环：填初始表（松\弛列为基）→ 算检验数 σj = cj − ΣcBiaij → σ 全 ≤ 0 则最优（max）→ 否则取最大 σ 列进基 → 最小比值 θ = b/a 定出基行 → 主元化 1、列化 0，重复。
④ 大M法：人工变量目标系数 −M（max），最优表中人工变量仍 > 0 ⇒ 无可行解。
⑤ 解的判别：σ ≤ 0 且某非基变量 σ = 0 ⇒ 无穷多最优解；某 σk > 0 且该列 aik 全 ≤ 0 ⇒ 无界解。
例2-1（建模，教材例2-1原型） 某厂生产产品 I、II，单位利润 80 元、100 元。资源消耗与限额：劳动力（8, 4）限额 360 工时；设备（4, 5）限额 200 台时；原材料A（3, 10）限额 250 公斤；原材料B（4, 6）限额 200 公斤。如何安排生产使利润最大？（只要求建模）
  1. 设 x1、x2 为产品 I、II 的产量。
  2. 目标：max z = 80x1 + 100x2
  3. 约束：8x1+4x2 ≤ 360（劳动力）；4x1+5x2 ≤ 200（设备）；3x1+10x2 ≤ 250（材料A）；4x1+6x2 ≤ 200（材料B）；x1,x2 ≥ 0
参考答案：如上模型。（进一步求解可得最优 x1=42.5, x2=5，z=3900，为约束1与约束4交点。）
例2-2（图解法） max z = 2x1 + 3x2，s.t. x1+2x2 ≤ 8，4x1 ≤ 16，4x2 ≤ 12，x1,x2 ≥ 0。用图解法求最优解。
  1. 画三条约束线：x1+2x2=8（过 (8,0)、(0,4)）；x1=4；x2=3。可行域为五边形，顶点：(0,0)、(4,0)、(4,2)、(2,3)、(0,3)。
  2. 逐点代入 z = 2x1+3x2：(0,0)→0；(4,0)→8；(4,2)→14；(2,3)→13；(0,3)→9。
  3. 也可画等值线 2x1+3x2=k 向右上平移，最后接触的顶点为 (4,2)。
答案：x* = (4, 2)，zmax = 14。考点：最优解必在顶点取得；等值线斜率介于两约束线之间时会出现整条边最优（见例2-5）。

例2-4（大M法） min z = −3x1 + x2 + x3，s.t. x1−2x2+x3 ≤ 11；−4x1+x2+2x3 ≥ 3；−2x1+x3 = 1；x ≥ 0。
  1. 标准化：约束1加松弛 x4；约束2减剩余 x5、加人工 x6；约束3加人工 x7。目标改为 min z = −3x1+x2+x3+0x4+0x5+Mx6+Mx7。
  2. 初始基 (x4, x6, x7)，b = (11, 3, 1)。由于 cB 含 M，检验数含 M 项：M 的系数决定正负（M 视为无穷大）。
  3. 迭代路径（min 问题取 σ<0 且最负者进基）：x1 进基 → x7 出基；x3 进基 → x6 出基；x2 进基 → x4 出基，人工变量全部出基。
  4. 得基 (x1, x3, x2) = (4, 9, 1)，σ 全 ≥ 0（min），最优。
答案：x* = (4, 1, 9)，zmin = −12+1+9 = −2。验证：4−2+9=11 ✓；−16+1+18=3 ✓；−8+9=1 ✓。判据：最优表中人工变量仍取正值 ⇒ 原问题无可行解。
例2-5（解的判别：多重最优解） max z = 2x1 + 4x2，s.t. x1+2x2 ≤ 8，4x1 ≤ 16，4x2 ≤ 12，x ≥ 0。判别并求全部最优解。
  1. 可行域顶点：(0,0)、(4,0)、(4,2)、(2,3)、(0,3)。
  2. z 值：0、8、16、16、12。两个相邻顶点 (4,2)、(2,3) 同为最优 ⇒ 目标线 2x1+4x2=16 与约束 x1+2x2=8 平行（斜率同为 −1/2）。
  3. 单纯形表特征：最优表中某非基变量检验数 σ = 0 ⇒ 无穷多最优解。
答案：最优解为 (4,2) 与 (2,3) 连线上全部点 x = λ(4,2)+(1−λ)(2,3)（0≤λ≤1），zmax = 16。对照：若 σk>0 且第 k 列系数全 ≤ 0 ⇒ 无界解；初始基都构造不出 ⇒ 加人工变量后仍不为 0 ⇒ 无可行解。

3第3章 对偶理论与敏感性分析 必考

建议用时：1.5 小时 · 与第2章常合为一道大题
必背套路：
① 写对偶（max, ≤ 型原问题）：每个约束配一个对偶变量 yi ≥ 0；目标系数 ↔ 右端项互换；系数矩阵转置；原 max ≤ ⇒ 对偶 min ≥。
② 互补松弛：xj > 0 ⇒ 对偶第 j 个约束取等号；原第 i 个约束严格成立（松弛 > 0）⇒ yi = 0。
③ 影子价格 = 对偶最优解 yi* = 资源 i 每增加 1 单位带来的 z 增量（在灵敏度范围内成立）。
④ 灵敏度分析（保持最优基不变）：c 变化 ⇒ 重算检验数 σ ≤ 0 解不等式；b 变化 ⇒ 算 B−1(b+Δb) ≥ 0 解不等式。
⑤ 对偶单纯形法：适用于「σ 已全部 ≤ 0 但 b 有负分量」（如增加约束后）：选最负 b 行出基 → 负系数中 min |σ/a| 进基 → 迭代至 b 全 ≥ 0。
例3-1（写对偶） 写出例2-2 原问题（max z=2x1+3x2，x1+2x2≤8，4x1≤16，4x2≤12，x≥0）的对偶问题。
  1. 三个约束 → 三个对偶变量 y1, y2, y3 ≥ 0。
  2. 右端项 (8,16,12) 成为目标系数；原 max、≤ ⇒ 对偶 min、≥。
  3. 系数矩阵转置：x1 列 (1,4,0)、x2 列 (2,0,4) 成为两个对偶约束的系数。
答案：min w = 8y1+16y2+12y3；s.t. y1+4y2 ≥ 2；2y1+4y3 ≥ 3；y1,y2,y3 ≥ 0
速查：原问题约束为「=」⇒ 对偶变量自由（无符号限制）；原变量自由 ⇒ 对偶约束取「=」。
例3-2（互补松弛求对偶解 + 影子价格） 已知例2-2 最优解 x*=(4,2)，z=14。不求解对偶，直接求 y* 并解释经济含义。
  1. 检验原约束松紧：约束1：4+2×2=8（紧）；约束2：4×4=16（紧）；约束3：4×2=8 < 12（松）⇒ y3=0。
  2. x1=4 > 0 ⇒ y1+4y2=2；x2=2 > 0 ⇒ 2y1+4y3=3。
  3. 代入 y3=0：y1=3/2；再由 y1+4y2=2 得 y2=1/8。
  4. 验证：w = 8×(3/2)+16×(1/8)+0 = 12+2 = 14 = z ✓（强对偶定理）。
答案：y* = (3/2, 1/8, 0)，w = 14。含义：资源1、2 的影子价格分别为 1.5、0.125 元/单位；资源3 有剩余，影子价格为 0。
例3-3（对偶单纯形法） min z = 2x1+x2，s.t. 3x1+x2 ≥ 3；4x1+3x2 ≥ 6；x1+2x2 ≥ 3；x ≥ 0。
  1. 约束乘 −1 化为 ≤，加松弛 x3,x4,x5：−3x1−x2+x3=−3；−4x1−3x2+x4=−6；−x1−2x2+x5=−3。初始基 (x3,x4,x5)，b=(−3,−6,−3)，σ=(−2,−1,0,0,0) 已全 ≤ 0（按 max z′=−z）⇒ 对偶可行，可用对偶单纯形法。
  2. 迭代1：b 最负为 x4 行（−6），x4 出基；负系数中 min{|−2/−4|, |−1/−3|} = 1/3 ⇒ x2 进基，主元 −3。得 b=(−1, 2, 1)，x2=2。
  3. 迭代2：x3 行 b=−1，x3 出基；负系数 min{|(−2/3)/(−5/3)|, |(−1/3)/(−1/3)|} = 2/5 ⇒ x1 进基，主元 −5/3。得 b=(3/5, 6/5, 0) 全 ≥ 0，停止。
答案：x* = (3/5, 6/5)，zmin = 2×(3/5)+6/5 = 12/5 = 2.4。用途：灵敏度分析中 b 变化使某分量变负时，接着原最优表用此法迭代，不必从头算。
例3-4（灵敏度：c 变化范围） 例2-2 中最优基为 (x1,x2,x5)。问产品 I 的利润 c1（原值 2）在什么范围内变化时最优生产方案不变？c2（原值 3）呢？
  1. c 变化只影响检验数。非基变量为 x3,x4，其检验数：σ3 = −3/2（不含 c1，恒 ≤ 0）；σ4 = 3/8 − c1/4。
  2. 保持最优要求 σ4 ≤ 0 ⇒ 3/8 − c1/4 ≤ 0 ⇒ c1 ≥ 3/2。
  3. 同理对 c2：σ4 = −1/2 + c2/8 ≤ 0 ⇒ c2 ≤ 4（σ3=−c2/2 恒 ≤ 0）。
答案：c1 ∈ [3/2, +∞)，c2 ∈ (−∞, 4] 时最优基（即生产方案结构）不变。注意：此结论的前提是「只变一个系数、最优基不变」；方案不变但 z 值会变。
例3-5（灵敏度：b 变化 + 影子价格应用） 例2-2 中资源2 的限量 b2（原值 16）允许变化范围是多少？若 b2 从 16 增加到 18，最优解和利润如何变？（最优基 B 对应的 B−1 的第 2 列为 (1/4, −1/8, 1/2)T，基解 (4, 2, 4)T）
  1. 设 b2=16+Δ，新基解 = 原基解 + Δ×(B−1 第2列)：(4+Δ/4, 2−Δ/8, 4+Δ/2)。
  2. 要求全 ≥ 0：Δ ≥ −16；Δ ≤ 16；Δ ≥ −8 ⇒ −8 ≤ Δ ≤ 16，即 b2 ∈ [8, 32]。
  3. b2：16→18，Δ=2（在范围内）：新解 x1=4.5，x2=1.75（x5=5）。
  4. 新利润：z = 2×4.5+3×1.75 = 14.25，恰等于 14 + y2×Δ = 14 + 0.125×2 = 14.25 ✓（影子价格直接算增量）。
答案：b2 ∈ [8, 32]；b2=18 时 x*=(4.5, 1.75)，z=14.25。技巧：范围内直接用「Δz = 影子价格 × Δb」，超出范围影子价格失效需重解。

4第4章 运输问题 必考

建议用时：1 小时 · 表上作业法步骤固定，是全场最「套路」的大题
必背套路：
① 产销平衡表：Σ产量 = Σ销量才能直接做；不平衡先加虚拟行/列（运费 0）。
② 初始方案：最小元素法（每次选全表最小运费格尽量分配）；伏格尔法（算行/列罚数 = 最小与次小之差，在罚数最大行/列的最小元素处分配）——伏格尔法通常更接近最优。
③ 基格数 = m + n − 1，不足要补 0 基格（退化）。
④ 位势法检验：基格 ui+vj=cij，令 u1=0 解出全部位势；非基格检验数 σij = cij−(ui+vj)，全 ≥ 0 ⇒ 最优（min）。
⑤ 闭回路调整：取最负 σ 格，画「+−交替」唯一闭回路，θ = 减号格最小运量，加减调整后重新检验。
例4-1（最小元素法求初始方案） 三个产地 A1A2A3 产量 7、4、9；四个销地 B1～B4 销量 3、6、5、6。单位运价表：A1：(3, 11, 3, 10)；A2：(1, 9, 2, 8)；A3：(7, 4, 10, 5)。求初始调运方案及费用。
  1. 全表最小为 c21=1：x21=min(4,3)=3，B1 满足，A2 余 1。
  2. 剩余最小 c23=2：x23=min(1,5)=1，A2 用完，B3 余 4。
  3. 最小 c13=3：x13=min(7,4)=4，B3 满足，A1 余 3。
  4. 最小 c32=4：x32=min(9,6)=6，B2 满足，A3 余 3。
  5. 最小 c34=5：x34=min(3,6)=3，A3 用完，B4 余 3；最后 x14=3。
  6. 基格数 = 6 = 3+4−1 ✓。
答案：x13=4, x14=3, x21=3, x23=1, x32=6, x34=3；费用 = 4×3+3×10+3×1+1×2+6×4+3×5 = 86。
例4-2（位势法检验 + 闭回路调整） 对例4-1 的初始方案进行最优性检验并调整至最优。
  1. 令 u1=0，由基格 x13、x14 得 v3=3、v4=10；由 x34 得 u3=−5；由 x32 得 v2=9；由 x23 得 u2=−1；由 x21 得 v1=2。
  2. 非基格检验数 σij=cij−(ui+vj)：σ11=1，σ12=2，σ22=1，σ24=8−(−1+10)=−1，σ31=10，σ33=12。存在负值 ⇒ 非最优。
  3. x24 进基，闭回路：x24(+) → x23(−) → x13(+) → x14(−) → 回 x24。θ = min(x23, x14) = min(1,3) = 1。
  4. 调整：x24=1，x23=0（出基），x13=5，x14=2。新费用 = 86 − 1×1 = 85。重算位势，全部 σ ≥ 0 ⇒ 最优。
答案：最优方案 x13=5, x14=2, x21=3, x24=1, x32=6, x34=3；最小总运费 = 5×3+2×10+3×1+1×8+6×4+3×5 = 85。
例4-3（伏格尔法） 用伏格尔法求例4-1 问题的初始方案。
  1. 第一轮行罚数：A1 行 (3,11,3,10)：3−3=0；A2 行 (1,9,2,8)：2−1=1；A3 行 (7,4,10,5)：5−4=1。列罚数：B1：3−1=2，B2：9−4=5，B3：3−2=1，B4：8−5=3。最大罚数为 B2 列（5）→ 该列最小元素 c32=4：x32=min(9,6)=6，B2 列删去，A3 余 3。
  2. 重复计算罚数逐次分配：x21=3（c=1）、x34=3（c=5，罚数最大行）、x24=1（c=8）、x13=5、x14=2。
答案：伏格尔法初始方案 x13=5, x14=2, x21=3, x24=1, x32=6, x34=3，费用 85 —— 直接达到最优（伏格尔法常常一步到位，但考试仍须做位势法检验加以确认）。
例4-4（产销不平衡） 产地 A1A2A3 产量 8、6、5（共 19）；销地 B1B2B3 销量 4、8、5（共 17）。运价：A1：(4, 12, 4)；A2：(6, 8, 5)；A3：(9, 7, 7)。求最小费用调运方案。
  1. 产 > 销，多 2 单位 ⇒ 增设虚拟销地 B4（库存），销量 2，运价全 0，化为平衡问题。
  2. 按表上作业法求解（最小元素法 + 位势法），关键判断：虚拟列的 0 运费格最后分配，谁先「库存」由全局最优决定。
  3. 最优分配：x11=4，x13=4，x22=3，x23=1，x2→虚=2，x32=5。
答案：最小费用 = 4×4+4×4+8×3+5×1+0×2+7×5 = 16+16+24+5+0+35 = 96（A2 产地留 2 单位不运）。对照：销 > 产时加虚拟产地，运价同样取 0。
例4-5（最大化运输问题） 两个产地 A1A2 产量 10、15；三个销地 B1B2B3 销量 8、9、8。单位利润表：A1：(6, 4, 7)；A2：(5, 8, 4)。求总利润最大的分配。
  1. 最大化问题的两种处理：① 初始方案用「最大元素法」，检验标准改为 σij = cij−(ui+vj) ≤ 0 全部成立为最优；② 或把利润表取负 / 用 M−cij 转化为最小化。
  2. 最大元素法：c22=8 最大：x22=min(15,9)=9；c13=7：x13=min(10,8)=8，A1 余 2；c11=6：x11=2，A1 用完；剩余 x21=6。
  3. 位势法（max 判据 σ ≤ 0）检验：u1=0，v1=6，v3=7；u2=−1（x21），v2=9（x22）。σ12=4−9=−5 ≤ 0 ✓；σ23=4−6=−2 ≤ 0 ✓ ⇒ 最优。
答案：x11=2, x13=8, x21=6, x22=9；最大利润 = 2×6+8×7+6×5+9×8 = 12+56+30+72 = 170。易错点：最大化时忘记反转检验数判据是最常见扣分点。

5第5章 线性目标规划 偶考

建议用时：25 分钟 · 考试以建模为主，求解只考小图/小表
必背套路：
① 偏差变量：每个目标约束配 d⁻（负偏差，未达量）、d⁺（正偏差，超出量），且 d⁻·d⁺=0。
② 目标约束写法：f(x) + d⁻ − d⁺ = 目标值。
③ 目标函数取舍：想「恰好达到」⇒ min(d⁻+d⁺)；想「不低于」（≥）⇒ min d⁻；想「不超过」（≤）⇒ min d⁺。
④ 优先级：min z = P1(·) + P2(·) + …，P1 ≫ P2 ≫ …，先满足高优先级；同级内用权系数 w 区分。
⑤ 硬约束（绝对约束）不进目标函数，必须严格满足。
例5-1（建模） 某厂生产 A、B 两种产品，单位利润 10、8 元；设备工时约束 2x1+x2 ≤ 11（硬约束）。目标：P1：总利润不低于 56 元；P2：原材料消耗 x1+2x2 不超过 15；P3：A 的产量不少于 B。建立目标规划模型。
  1. 硬约束：2x1+x2 ≤ 11。
  2. 三个目标约束：10x1+8x2+d1⁻−d1⁺=56；x1+2x2+d2⁻−d2⁺=15；x1−x2+d3⁻−d3⁺=0。
  3. 取舍：P1「不低于」⇒ min d1⁻；P2「不超过」⇒ min d2⁺；P3「不少于」⇒ min d3⁻。
答案：min z = P1d1⁻ + P2d2⁺ + P3d3⁻；s.t. 上述 1 个硬约束 + 3 个目标约束；全部变量 ≥ 0
例5-2（图解法） min z = P1d1⁻ + P2d2⁺ + P3d3⁻；目标约束：G1：x1+x2+d1⁻−d1⁺=10；G2：x1+2x2+d2⁻−d2⁺=14；G3：x1+3x2+d3⁻−d3⁺=30；硬约束 0 ≤ x1,x2 ≤ 8。
  1. P1 级：令 d1⁻=0 ⇒ 满意区域 R1：x1+x2 ≥ 10（正方形内右上部分）。
  2. P2 级：在 R1 内令 d2⁺=0 ⇒ x1+2x2 ≤ 14 ⇒ 满意区域收缩为三角形，顶点 (6,4)、(8,2)、(8,3)。
  3. P3 级：在三角形内最大化 x1+3x2（使 d3⁻ 最小）：(6,4)→18；(8,2)→14；(8,3)→17，最大为 18 < 30。
答案：满意解 x* = (6, 4)；d1⁻=0（利润目标达成），d2⁺=0（材料目标达成），d3⁻ = 30−18 = 12（第三目标欠 12 单位，因优先级最低被放弃）。
例5-3（单纯形法思想） min z = P1d1⁻ + P2d2⁺；G1：x1+x2+d1⁻−d1⁺=8；G2：2x1+2x2+d2⁻−d2⁺=10；x,d ≥ 0。求满意解。
  1. 目标规划单纯形表的特点：检验数按优先级分行（P1 行、P2 行），先看 P1 行全部 ≥ 0 才看 P2 行；高级目标未最优前，不允许为改善低级目标而牺牲高级目标。
  2. P1 级：min d1⁻。显然 x1+x2 ≥ 8 可满足（如 x1=8）⇒ d1⁻* = 0，P1 级达成。
  3. P2 级：在 x1+x2 ≥ 8 的前提下 min d2⁺ = max(0, 2(x1+x2)−10)。最小化即取 x1+x2=8 ⇒ d2⁺ = 16−10 = 6。
答案：满意解为满足 x1+x2=8 的任意非负点（如 x*=(8,0)）；d1⁻=0，d2⁺=6。考点：两个目标冲突时严格按优先级取舍——这是目标规划与普通 LP 的本质区别。
例5-4（建模：广告预算分配） 某公司有广告预算 60 万元，电视广告每万元带来曝光 5 千次、报纸 3 千次。目标：P1：总曝光不少于 250 千次；P2：电视投入不超过报纸的 2 倍（尽量避免电视占比过大，超出部分越小越好）；P3：尽量用完预算。建模。
  1. 设 x1、x2 为电视、报纸投入（万元）。
  2. 目标约束：5x1+3x2+d1⁻−d1⁺=250；x1−2x2+d2⁻−d2⁺=0；x1+x2+d3⁻−d3⁺=60。
  3. 取舍：P1 min d1⁻；P2 min d2⁺；P3「用完」即不低于 60 ⇒ min d3⁻。
答案：min z = P1d1⁻ + P2d2⁺ + P3d3⁻ + 三个目标约束，x,d ≥ 0
例5-5（建模综合 + 优先级设置原则） 某厂用一条生产线生产两种产品，正常工时为 100 小时。产品 A 每件 2 工时、利润 40 元；产品 B 每件 1 工时、利润 30 元。经营者要求：P1：尽量避免加班（总工时不超过 100）；P2：利润力争达到 2600 元；P3：B 的市场需求上限 40 件尽量不要超产。建模并说明优先级理由。
  1. 目标约束：2x1+x2+d1⁻−d1⁺=100；40x1+30x2+d2⁻−d2⁺=2600；x2+d3⁻−d3⁺=40。
  2. 取舍：P1 min d1⁺（加班量）；P2 min d2⁻；P3 min d3⁺。
答案：min z = P1d1⁺ + P2d2⁻ + P3d3⁺
优先级原则：① 涉及安全/法规/合同的目标排最高；② 经营者明确强调的排前；③ 同一优先级内多个子目标用权系数 w 区分（写在括号内，如 P2(2d2⁻+d4⁻)）。

6第6章 整数规划 必考

建议用时：1 小时 · 匈牙利法几乎年年考，分支定界要会画树
必背套路：
① 分支定界（max）：解 LP 松弛 → 若解为整数即最优；否则取分数变量 xj=v 分两枝（xj ≤ ⌊v⌋、xj ≥ ⌈v⌉）→ 各枝再解 LP → 整数解更新下界 z；某枝 LP 值 ≤ z 或不可行 ⇒ 剪枝。
② 0-1 建模：互斥选其一：x1+x2=1；至多其一：x1+x2 ≤ 1；选 A 才可选 B：x2 ≤ x1；固定费用：ciyi + …，y∈{0,1}。
③ 隐枚举：先试探一个可行解得过滤条件 z ≥ z0，凡不满足过滤条件或任一约束的枝直接剪掉。
④ 匈牙利法：行变换（每行减行最小）→ 列变换（每列减列最小）→ 用最少数直线覆盖全部 0：若线数 = n 则选 n 个独立 0 得最优；否则在未覆盖部分找最小元素 θ，未覆盖行减 θ、覆盖列加 θ，重复。
例6-1（分支定界法） max z = 40x1+90x2，s.t. 9x1+7x2 ≤ 56；7x1+20x2 ≤ 70；x1,x2 ≥ 0 且为整数。
  1. 节点0（LP 松弛）：x=(4.81, 1.82)，z=355.9。非整数，取 x1 分枝：x1 ≤ 4 / x1 ≥ 5。
  2. 节点B1（x1 ≤ 4）：LP 解 (4, 2.1)，z=349。取 x2 分枝：x2 ≤ 2 / x2 ≥ 3。
  3. 节点B3（x1≤4, x2≤2）：LP 解 (4, 2) 整数！z=340，记为当前下界 z̲=340。节点B4（x1≤4, x2≥3）：LP 解 (1.43, 3)，z=327.1 < 340 ⇒ 剪枝。
  4. 节点B2（x1 ≥ 5）：LP 解 (5, 1.57)，z=341.4 > 340，继续分枝：x2 ≤ 1 / x2 ≥ 2。B5（x2≤1）：z=307.8 < 340 剪枝；B6（x2≥2）：LP 不可行，剪枝。
答案：x* = (4, 2)，zmax = 340。要点：LP 松弛值是各枝的「上界」，整数可行解不断更新「下界」，上界 ≤ 下界即剪。
例6-2（0-1 建模：选址） 候选仓库地址 3 处，建造费 100、150、120 万元；需求点 4 个，仓库 i 能覆盖需求点集合 S1={1,2}，S2={2,3,4}，S3={1,4}。要求每个需求点至少被一个仓库覆盖，且地址 1 与地址 2 至多建一个。总建造费最小，建模（不求解）。
  1. 设 yi=1 表示在地址 i 建库，否则 0（i=1,2,3）。
  2. 目标：min z = 100y1+150y2+120y3。
  3. 覆盖约束：点1：y1+y3 ≥ 1；点2：y1+y2 ≥ 1；点3：y2 ≥ 1；点4：y2+y3 ≥ 1。
  4. 互斥：y1+y2 ≤ 1。
答案：模型如上。点评：点3 的约束直接定出 y2=1，进而 y1=0，再看点4 要求 y3 ≥ 0 配合 y2=1 已满足 ⇒ 最优 y=(0,1,0)，费用 150——考场上建模题常附送「顺便求解」的小分。
例6-3（隐枚举法） max z = 3x1−2x2+5x3，s.t. x1+2x2−x3 ≤ 2；x1+4x2+x3 ≤ 4；x1+x2 ≤ 3；4x1+x3 ≤ 6；x∈{0,1}。
  1. 试探：目标系数大的变量先取 1。试 (1,0,1)：四个约束 0≤2 ✓、2≤4 ✓、1≤3 ✓、5≤6 ✓，可行，z=8 ⇒ 过滤条件 z ≥ 8。
  2. 枚举其余组合时先查过滤条件：含 x2=1 的组合 z ≤ 3−2+5=6 < 8，全剪；不含 x2 的组合中 z 最大即 (1,0,1)=8。
答案：x* = (1, 0, 1)，zmax = 8。技巧：按目标系数从大到小确定试探顺序，通常第一步试探即得最优，过滤条件会剪掉绝大多数组合。
例6-4（匈牙利法） 四项任务甲乙丙丁由四人 A、B、C、D 完成（每人一项），效率矩阵（数值为成本）： A：(2, 15, 13, 4)；B：(10, 4, 14, 15)；C：(9, 14, 16, 13)；D：(7, 8, 11, 9)。求最小成本指派。
  1. 行变换（减行最小 2,4,9,7）： (0,13,11,2)；(6,0,10,11)；(0,5,7,4)；(0,1,4,2)。
  2. 列变换（列最小 0,0,4,0，仅第3列再减4）： (0,13,7,2)；(6,0,6,11)；(0,5,3,4)；(0,1,0,2)。
  3. 试覆盖：此时独立 0 不足 4 个，继续按规则调整（未覆盖部分最小元素 θ，未覆盖行减 θ、交叉列加 θ），最终得到 4 个独立 0：A→任务4，B→任务2，C→任务1，D→任务3。
答案：指派 A→4, B→2, C→1, D→3；最小成本 = 4+4+9+11 = 28。判据：能选出 n 个不同行不同列的 0 元素时即为最优。
例6-5（最大化指派） 五人五项任务的效益矩阵：甲：(12, 7, 9, 7, 9)；乙：(8, 9, 6, 6, 6)；丙：(7, 17, 12, 14, 9)；丁：(15, 14, 6, 6, 10)；戊：(4, 10, 7, 10, 9)。求总效益最大的指派。
  1. 最大化 ⇒ 转化：找出全矩阵最大元素 M=17，构造新矩阵 bij = 17 − aij，对新矩阵用匈牙利法求最小成本，还原即得最大效益指派。
  2. 转化后求解（行列变换 + 覆盖调整），得独立 0 对应：甲→任务3，乙→任务5，丙→任务2，丁→任务1，戊→任务4。
答案：最大效益 = 9+6+17+15+10 = 57。变体：人数 ≠ 任务数时先补虚拟行/列（元素取 0）化为方阵；「某人不能做某事」时对应元素取 M（充分大）。
