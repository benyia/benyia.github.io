一、运输问题求解方法：最小元素法与伏格尔法 产销平衡 · 位势法 · 闭回路调整
方法核心原理与规范要求：

运输问题是一类特殊的线性规划问题。通常采用最小元素法（就近供应原则）或伏格尔法（最大罚数法/差额法）确定初始基可行解（共 $m+n-1$ 个基变量格）；随后利用位势法（对偶变量法）设定某一 $u_i=0$，依据基变量格满足 $u_i + v_j = c_{ij}$ 解出所有行位势 $u_i$ 与列位势 $v_j$；再由公式 $\sigma_{ij} = c_{ij} - (u_i + v_j)$ 计算所有非基变量的检验数：若所有 $\sigma_{ij} \ge 0$，则当前解为最优解；若存在 $\sigma_{ij} < 0$，则选取负值最大者作为进基变量，作闭回路并确定调整量 $\theta$，进行数字格调整，直至达到最优解。

【例题 1】最小元素法求初始解 + 位势法检验 + 闭回路调整法 经典产销平衡运输模型

【题目描述】

某公司拥有三个化工厂 $A_1, A_2, A_3$，日产量分别为 $16\text{ t}, 10\text{ t}, 22\text{ t}$；产品销往四个销售点 $B_1, B_2, B_3, B_4$，日需求量分别为 $8\text{ t}, 14\text{ t}, 12\text{ t}, 14\text{ t}$。各产地到各销地的单位运价（元/吨）如下表所示。请用最小元素法编制初始调运方案，用位势法进行最优性检验；若非最优，用闭回路法进行调整，求出最低运费方案。

$B_1$ (8) $B_2$ (14) $B_3$ (12) $B_4$ (14)
$A_1$ 41241116
$A_2$ 2103910
$A_3$ 8511622
需求合计 814121450 (平衡)

第一步：验证产销平衡关系

总产量 $\sum a_i = 16 + 10 + 22 = 50$，总销量 $\sum b_j = 8 + 14 + 12 + 14 = 50$。产销平衡，基变量数为 $m + n - 1 = 3 + 4 - 1 = 6$ 个。

第二步：最小元素法编制初始调运方案（写出初始基可行解）

  1. 全局最小运价为 $c_{21} = 2$：分配 $x_{21} = \min(a_2, b_1) = \min(10, 8) = 8$。销地 $B_1$ 需求完全满足，划去第 1 列，$A_2$ 剩余供应量 $10 - 8 = 2$。
  2. 剩余格中最小运价为 $c_{23} = 3$：分配 $x_{23} = \min(2, 12) = 2$。产地 $A_2$ 供应完毕，划去第 2 行，$B_3$ 尚余需求 $12 - 2 = 10$。
  3. 未划去格中最小运价为 $c_{13} = 4$：分配 $x_{13} = \min(16, 10) = 10$。销地 $B_3$ 需求完全满足，划去第 3 列，$A_1$ 剩余供应量 $16 - 10 = 6$。
  4. 未划去格中最小运价为 $c_{32} = 5$：分配 $x_{32} = \min(22, 14) = 14$。销地 $B_2$ 需求完全满足，划去第 2 列，$A_3$ 剩余供应量 $22 - 14 = 8$。
  5. 未划去格中最小运价为 $c_{34} = 6$：分配 $x_{34} = \min(8, 14) = 8$。产地 $A_3$ 供应完毕，划去第 3 行，$B_4$ 尚余需求 $14 - 8 = 6$。
  6. 最后仅剩 $(1,4)$ 格，运价 $c_{14} = 11$：分配 $x_{14} = 6$，供需同时满足。

初始基可行解包含 6 个数字格：$(2,1)=8, (2,3)=2, (1,3)=10, (1,4)=6, (3,2)=14, (3,4)=8$。无退化现象。

初始总运费： $$z_0 = 8\times 2 + 2\times 3 + 10\times 4 + 6\times 11 + 14\times 5 + 8\times 6 = 16 + 6 + 40 + 66 + 70 + 48 = 246\text{ 元}$$

第三步：初始方案的位势法计算与最优性判定

设定行位势 $u_1 = 0$。根据基变量格满足 $u_i + v_j = c_{ij}$：

  • 对基格 $(1,3)$：$u_1 + v_3 = c_{13} \implies 0 + v_3 = 4 \implies v_3 = 4$
  • 对基格 $(1,4)$：$u_1 + v_4 = c_{14} \implies 0 + v_4 = 11 \implies v_4 = 11$
  • 对基格 $(2,3)$：$u_2 + v_3 = c_{23} \implies u_2 + 4 = 3 \implies u_2 = -1$
  • 对基格 $(2,1)$：$u_2 + v_1 = c_{21} \implies -1 + v_1 = 2 \implies v_1 = 3$
  • 对基格 $(3,4)$：$u_3 + v_4 = c_{34} \implies u_3 + 11 = 6 \implies u_3 = -5$
  • 对基格 $(3,2)$：$u_3 + v_2 = c_{32} \implies -5 + v_2 = 5 \implies v_2 = 10$

计算各非基变量格检验数 $\sigma_{ij} = c_{ij} - (u_i + v_j)$：

  • $\sigma_{11} = c_{11} - (u_1 + v_1) = 4 - (0 + 3) = 1 \ge 0$
  • $\sigma_{12} = c_{12} - (u_1 + v_2) = 12 - (0 + 10) = 2 \ge 0$
  • $\sigma_{22} = c_{22} - (u_2 + v_2) = 10 - (-1 + 10) = 1 \ge 0$
  • 非最优格 $\sigma_{24} = c_{24} - (u_2 + v_4) = 9 - (-1 + 11) = -1 < 0$！
  • $\sigma_{31} = c_{31} - (u_3 + v_1) = 8 - (-5 + 3) = 10 \ge 0$
  • $\sigma_{33} = c_{33} - (u_3 + v_3) = 11 - (-5 + 4) = 12 \ge 0$

由于 $\sigma_{24} = -1 < 0$，该初始方案不是最优解，需进行闭回路调整。

第四步：闭回路调整与最优方案确定

第一步：伏格尔法迭代计算过程（按最大行/列罚数分配）

伏格尔法的基本思想是：在各行或各列中计算出“次小运价与最小运价之差”（罚数/差额），差额最大者代表如果不按该方向的最小运价调运，将造成最大的运费惩罚，因而优先在最大罚数所在的行或列中选择最小运价格进行最大可能分配。

【第 1 轮罚数计算】

  • 行罚数：第1行 $|4 - 3| = 1$；第2行 $|6 - 2| = 4$；第3行 $|4 - 3| = 1$
  • 列罚数：第1列 $|6 - 3| = 3$；第2列 $|10 - 4| = 6$（最大罚数）；第3列 $|4 - 2| = 2$；第4列 $|5 - 3| = 2$
  • 决策：最大罚数为第 2 列（罚数 6）。该列最小运价为 $c_{32} = 4$。分配 $x_{32} = \min(a_3, b_2) = \min(20, 25) = 20$。
  • 状态更新：产地 $A_3$ 供应完毕，划去第 3 行；销地 $B_2$ 尚余需求 $25 - 20 = 5$。

【第 2 轮罚数计算】（剔除第 3 行）

  • 行罚数：第1行 $|4 - 3| = 1$；第2行 $|6 - 2| = 4$（最大罚数）
  • 列罚数：第1列 $|6 - 3| = 3$；第2列 $|11 - 10| = 1$；第3列 $|4 - 2| = 2$；第4列 $|8 - 5| = 3$
  • 决策：最大罚数为第 2 行（罚数 4）。该行最小运价为 $c_{23} = 2$。分配 $x_{23} = \min(a_2, b_3) = \min(40, 25) = 25$。
  • 状态更新：销地 $B_3$ 需求完全满足，划去第 3 列；产地 $A_2$ 尚余产量 $40 - 25 = 15$。

【第 3 轮罚数计算】（剔除第 3 行、第 3 列）

  • 行罚数：第1行 $|5 - 3| = 2$；第2行 $|8 - 6| = 2$
  • 列罚数：第1列 $|6 - 3| = 3$；第2列 $|11 - 10| = 1$；第4列 $|8 - 5| = 3$
  • 破平决策：第 1 列与第 4 列并列最大罚数 3。第 1 列最小运价 $c_{11} = 3$，第 4 列最小运价 $c_{14} = 5$；选择运价更低的第 1 列。
  • 分配 $x_{11} = \min(a_1, b_1) = \min(30, 20) = 20$。销地 $B_1$ 需求完全满足，划去第 1 列；产地 $A_1$ 剩余供应量 $30 - 20 = 10$。

【第 4 轮罚数计算】（剩余第 1, 2 行与第 2, 4 列）

  • 行罚数：第1行 $|11 - 5| = 6$（最大罚数）；第2行 $|10 - 8| = 2$
  • 列罚数：第2列 $|11 - 10| = 1$；第4列 $|8 - 5| = 3$
  • 决策：最大罚数为第 1 行（罚数 6）。该行最小运价为 $c_{14} = 5$。分配 $x_{14} = \min(10, 20) = 10$。
  • 状态更新：产地 $A_1$ 供应完毕，划去第 1 行；销地 $B_4$ 尚余需求 $20 - 10 = 10$。

【第 5 轮收尾分配】

此时只剩产地 $A_2$（剩余 15），直接满足 $B_2$ 剩余的 5 和 $B_4$ 剩余的 10：分配 $x_{22} = 5,\ x_{24} = 10$。各点供需完全平衡。

基变量格共 6 个：$x_{11}=20,\ x_{14}=10,\ x_{22}=5,\ x_{23}=25,\ x_{24}=10,\ x_{32}=20$。

第二步：位势法验证初始解的最优性

选取基变量最多的第 2 行设定 $u_2 = 0$：

  • 由 $(2,2)$：$u_2 + v_2 = c_{22} \implies 0 + v_2 = 10 \implies v_2 = 10$
  • 由 $(2,3)$：$u_2 + v_3 = c_{23} \implies 0 + v_3 = 2 \implies v_3 = 2$
  • 由 $(2,4)$：$u_2 + v_4 = c_{24} \implies 0 + v_4 = 8 \implies v_4 = 8$

  • 由 $(1,4)$：$u_1 + v_4 = c_{14} \implies u_1 + 8 = 5 \implies u_1 = -3$

二、分支定界法 (Branch and Bound Method) 整数规划 · 松弛定界 · 树状分支 · 剪枝剪枝法则
方法核心原理与规范要求（依据教材第6章）：

求解最大化整数规划时：
1. 首先求解其不考虑整数约束的线性松弛规划，若得到的最优解刚好为整数解，则直接即为整数规划最优解；若为非整数解，其目标函数值构成原问题的一个上界 $\bar{z}$，任意已知可行整数解的目标值构成下界 $\underline{z}$。
2. 分支规则：选择一个非整数分量 $x_j^* = b_j$，构造两个互斥的约束条件：$x_j \le [b_j]$ 与 $x_j \ge [b_j] + 1$（其中 $[b_j]$ 表示不大于 $b_j$ 的最大整数），分别加入原模型形成两个子问题。
3. 剪枝（定界）准则： （1）子问题无可行解，剪枝； （2）子问题求得整数最优解，若其目标值优于现行下界，则更新下界 $\underline{z}$，并终止该支的进一步分支； （3）子问题松弛最优解目标值 $z \le \underline{z}$，不可能产生更优解，剪枝。 重复分支与定界过程，直至所有分支均被剪枝，现行下界对应的整数解即为最优解。

【例题 1】课后习题 6.1(1) 全整数线性规划的分支定界求解 《运筹学解题指导》第6章 习题 6.1(1)

【题目描述】

用分支定界法求解下列整数规划问题： $$\begin{aligned} \max \quad & z = 3x_1 + 2x_2 \\ \text{s.t.} \quad & 2x_1 + 3x_2 \le 14.5 \\ & 4x_1 + x_2 \le 16.5 \\ & x_1, x_2 \ge 0, \quad x_1, x_2 \text{ 为整数} \end{aligned}$$

📌 规范解答与完整分支树推导

第一步：求解初始线性规划松弛问题（记为 $B_0$）

暂时不考虑整数约束，联立两条约束直线边界： $$\begin{cases} 2x_1 + 3x_2 = 14.5 \\ 4x_1 + x_2 = 16.5 \end{cases}$$ 由第二式得 $x_2 = 16.5 - 4x_1$，代入第一式： $$2x_1 + 3(16.5 - 4x_1) = 14.5 \implies -10x_1 + 49.5 = 14.5 \implies 10x_1 = 35 \implies x_1 = 3.5$$ 代回得 $x_2 = 16.5 - 4\times 3.5 = 2.5$。 松弛问题最优解为：$X^{(0)} = \left(\dfrac{7}{2}, \dfrac{5}{2}\right)^T = (3.5, 2.5)^T$。 最优目标函数值：$z^{(0)} = 3\times 3.5 + 2\times 2.5 = 15.5$。 由于解含非整数分量，设置初始界：上界 $\bar{z} = 15.5$，由观察显见 $(0,0)$ 为可行整数解，初始下界 $\underline{z} = 0$。

第二步：对非整数变量 $x_1 = 3.5$ 进行第一轮分支

构造两个互斥子问题：$[3.5] = 3$，分支为 $x_1 \le 3$ 与 $x_1 \ge 4$。

子问题 $B_1$：加入约束 $x_1 \le 3$

约束系统为：$2x_1 + 3x_2 \le 14.5,\ 4x_1 + x_2 \le 16.5,\ 0 \le x_1 \le 3,\ x_2 \ge 0$。

在 $x_1 = 3$ 处，检验两条边界约束对 $x_2$ 的上限： $$2(3) + 3x_2 \le 14.5 \implies 3x_2 \le 8.5 \implies x_2 \le \frac{17}{6} \approx 2.833$$ $$4(3) + x_2 \le 16.5 \implies x_2 \le 4.5$$ 取较小者，得松弛最优解：$X^{(1)} = \left(3, \dfrac{17}{6}\right)^T$，目标函数值 $z_1 = 3\times 3 + 2\times \dfrac{17}{6} = \dfrac{44}{3} \approx 14.67$。 由于 $z_1 = 14.67 > \underline{z} = 0$，保留此分支待进一步分解。

子问题 $B_2$：加入约束 $x_1 \ge 4$

约束系统为：$2x_1 + 3x_2 \le 14.5,\ 4x_1 + x_2 \le 16.5,\ x_1 \ge 4,\ x_2 \ge 0$。

由 $4x_1 + x_2 \le 16.5$ 及 $x_1 \ge 4$ 可知：$x_1$ 最大只能取 $4.125$；当 $x_1 = 4$ 时，必须满足 $x_2 \le 16.5 - 16 = 0.5$。 此时 $2(4) + 3(0.5) = 9.5 \le 14.5$ 满足。 松弛最优解在边界交点取得：$X^{(2)} = (4, 0.5)^T$。 目标函数值：$z_2 = 3\times 4 + 2\times 0.5 = 13$。

第三步：对子问题 $B_1$ 的非整数分量 $x_2 = \dfrac{17}{6} \approx 2.833$ 进行第二轮分支

构造分支约束：$x_2 \le 2$ 与 $x_2 \ge 3$。

获得整数解 子问题 $B_3$：$x_1 \le 3,\ x_2 \le 2$

在区域 $x_1 \le 3, x_2 \le 2$ 内，显然在右上顶点 $x_1 = 3, x_2 = 2$ 处取得极大化目标函数值： $$z_3 = 3\times 3 + 2\times 2 = 13$$ 检验约束条件：$2(3) + 3(2) = 12 \le 14.5$（满足），$4(3) + 2 = 14 \le 16.5$（满足）。 该解全为整数！ 因此获得一个合格的整数可行解 $X = (3, 2)^T$，更新现行下界： $$\underline{z} = \max(\underline{z}, 13) = 13$$ 剪枝：由于本支已获得整数解，终止对 $B_3$ 的继续分支。

子问题 $B_4$：$x_1 \le 3,\ x_2 \ge 3$

由于要求 $x_2 \ge 3$，由第一条约束：$2x_1 + 3(3) \le 14.5 \implies 2x_1 \le 5.5 \implies x_1 \le 2.75$。 当 $x_1 = 2.75, x_2 = 3$ 时，检验第二条约束：$4(2.75) + 3 = 11 + 3 = 14 \le 16.5$ 满足。 松弛最优解为：$X^{(4)} = (2.75, 3)^T = \left(\dfrac{11}{4}, 3\right)^T$。 目标函数值：$z_4 = 3\times 2.75 + 2\times 3 = 14.25 = \dfrac{57}{4}$。 由于 $z_4 = 14.25 > \underline{z} = 13$，且 $x_1 = 2.75$ 为非整数，需对 $B_4$ 继续分支。

第四步：对子问题 $B_4$ 的非整数分量 $x_1 = 2.75$ 进行第三轮分支

构造分支约束：$x_1 \le 2$ 与 $x_1 \ge 3$。

剪枝 (界不优) 子问题 $B_5$：$x_1 \le 2,\ x_2 \ge 3$

由 $2x_1 + 3x_2 \le 14.5$ 及 $x_1 \le 2$：在 $x_1 = 2$ 处，$3x_2 \le 14.5 - 4 = 10.5 \implies x_2 \le 3.5$。 松弛最优解为 $x_1 = 2, x_2 = 3.5$，目标函数值 $z_5 = 3\times 2 + 2\times 3.5 = 13$。 由于 $z_5 = 13 \le \underline{z} = 13$，其松弛最优值不可能严格大于当前已知整数解，直接剪枝！

剪枝 (不可行) 子问题 $B_6$：$x_1 \ge 3$（且原已有 $x_1 \le 3, x_2 \ge 3$）

同时满足 $x_1 \ge 3$ 与 $x_1 \le 3$ 意味着只能取 $x_1 = 3$。 但当 $x_1 = 3, x_2 \ge 3$ 时，代入约束： $$2(3) + 3x_2 \ge 6 + 9 = 15 > 14.5$$ 这与原约束 $2x_1 + 3x_2 \le 14.5$ 发生矛盾！子问题 $B_6$ 可行域为空集，直接剪枝！

第五步：回溯考察未完成分支 $B_2$

剪枝 (界不优) 子问题 $B_2$：$x_1 \ge 4$

在第二步中计算出 $B_2$ 的松弛最优目标值为 $z_2 = 13$。 由于 $z_2 = 13 \le \underline{z} = 13$，该分支绝不可能产生优于 13 的整数解，无需继续分支，直接剪枝！

【最终最优解结论】

经过全面分支与定界搜索，所有分支已全部剪枝终止。最终唯一最优整数解为： $$x_1^* = 3, \quad x_2^* = 2, \quad \max z^* = 13$$

📌 规范解答与推导过程

第一步：求解松弛线性规划问题（$B_0$）

联立两条约束直线方程： $$\begin{cases} 2x_1 + 3x_2 = 14 \\ 2x_1 + x_2 = 9 \end{cases}$$ 两式相减可得：$2x_2 = 5 \implies x_2 = 2.5$。 代入第二式得：$2x_1 = 9 - 2.5 = 6.5 \implies x_1 = 3.25$。 松弛问题的最优解为： $$X^{(0)} = \left(\frac{13}{4}, \frac{5}{2}\right)^T = (3.25, 2.5)^T$$ 对应的连续最优目标值为： $$z^{(0)} = 3\times 3.25 + 2\times 2.5 = 9.75 + 5 = 14.75 = \frac{59}{4}$$ 目标函数上界 $\bar{z} = 14.75$，初始下界 $\underline{z} = 0$。解中 $x_1, x_2$ 均为非整数，需进行分支。

第二步：选择非整数变量 $x_1 = 3.25$ 进行分支

构造分支约束条件：$x_1 \le 3$（子问题 $B_1$）与 $x_1 \ge 4$（子问题 $B_2$）。

子问题 $B_1$：加入约束 $x_1 \le 3$

约束条件为：$2x_1 + 3x_2 \le 14,\ 2x_1 + x_2 \le 9,\ x_1 \le 3,\ x_1, x_2 \ge 0$。

分析可行域边界，在 $x_1 = 3$ 处： $$2(3) + 3x_2 \le 14 \implies 3x_2 \le 8 \implies x_2 \le \frac{8}{3} \approx 2.667$$ $$2(3) + x_2 \le 9 \implies x_2 \le 3$$ 因此 $x_2$ 最大取 $\dfrac{8}{3}$。 子问题 $B_1$ 的松弛最优解为：$X^{(1)} = \left(3, \dfrac{8}{3}\right)^T$。 最优目标函数值：$z_1 = 3\times 3 + 2\times \dfrac{8}{3} = 9 + \dfrac{16}{3} = \dfrac{43}{3} \approx 14.33$。

获得整数最优解候选 子问题 $B_2$：加入约束 $x_1 \ge 4$

约束条件为：$2x_1 + 3x_2 \le 14,\ 2x_1 + x_2 \le 9,\ x_1 \ge 4,\ x_1, x_2 \ge 0$。

由 $2x_1 + x_2 \le 9$ 与 $x_1 \ge 4$ 可知：$x_1$ 只能在 $[4, 4.5]$ 内取值。 为使目标函数 $3x_1 + 2x_2$ 尽可能大，在边界点 $x_1 = 4$ 处： $$2(4) + x_2 \le 9 \implies x_2 \le 1$$ 检验第一条约束：$2(4) + 3(1) = 11 \le 14$ 满足。 因此，在顶点 $(4, 1)$ 处取得最优解！ 由于 $x_1 = 4, x_2 = 1$ 均为整数，该解为整数可行解！ 其目标函数值为： $$z_2 = 3\times 4 + 2\times 1 = 14$$ 立即更新下界：$\underline{z} = \max(0, 14) = 14$。 剪枝：本支已达到整数解，终止对 $B_2$ 继续分支。

第三步：对子问题 $B_1$ 进行剪枝判定与验证

子问题 $B_1$ 的松弛最优值为 $z_1 = \dfrac{43}{3} \approx 14.33$。 由于原目标函数的系数 $(3, 2)$ 均为整数，对任意整数解 $(x_1, x_2)$，目标函数值 $z = 3x_1 + 2x_2$ 必为整数。 因此，$B_1$ 域内可能得到的整数目标值上限为 $[14.33] = 14$。 我们对 $B_1$ 进一步对非整数分量 $x_2 = 8/3 \approx 2.67$ 进行分支检验：

剪枝 (界不优) 分支 $x_2 \le 2$：

在 $x_1 \le 3, x_2 \le 2$ 约束下，最大可能目标值为 $z = 3(3) + 2(2) = 13$。 由于 $13 < \underline{z} = 14$，直接剪枝！

剪枝 (界不优) 分支 $x_2 \ge 3$：

代入约束 $2x_1 + 3(3) \le 14 \implies 2x_1 \le 5 \implies x_1 \le 2.5$。 最大目标值为 $z = 3(2.5) + 2(3) = 13.5$。 由于 $13.5 < \underline{z} = 14$，直接剪枝！

【最终最优解结论】

所有分支均已剪枝定界。整数规划的最优解为： $$x_1^* = 4, \quad x_2^* = 1, \quad \max z^* = 14$$

三、大M单纯形法 (Big-M Method) 人工变量 · 惩罚因子 · 最优解与无解判定
方法核心原理与规范要求（依据教材第2章第6节）：

当线性规划模型化为标准型后，若约束方程系数矩阵中不存在现成的单位矩阵（即缺乏初始基变量），需在相应的等式或“$\ge$”型约束中引入人工变量 $x_a \ge 0$。
在目标函数中对人工变量赋予一个绝对值极其巨大的负罚数 $-M$（极小化问题为 $+M$），使得在单纯形法迭代寻求最大化时，系统必然优先将人工变量驱逐出基。
终止判别法则： 1. 当所有检验数 $\sigma_j \le 0$，且所有人工变量均已出基（或虽在基中但取值为 0），则当前解为原问题的最优解； 2. 当所有检验数 $\sigma_j \le 0$，但基变量中仍含有人工变量且其取值严格大于 0，则判定原线性规划问题无可行解。

四、两阶段单纯形法 (Two-Phase Simplex Method) 辅助目标规划 · 第一阶段人工消除 · 第二阶段最优求解
方法核心原理与规范要求（依据教材第2章第6节）：

两阶段法避免了大M法中引入抽象大常数 $M$ 带来的计算机数值计算误差。
第一阶段：构造辅助问题，只含人工变量且以人工变量之和最小为目标（$\min w = \sum x_a$ 或 $\max (-w) = -\sum x_a$），原问题决策变量在辅助目标函数中的价值系数全置为 0。使用单纯形法求解该辅助问题：

  • 若最优目标值 $\min w = 0$，说明人工变量能被全部清零/驱逐出基，原问题存在可行解，转入第二阶段；
  • 若最优目标值 $\min w > 0$，说明不可能消除人工变量，原问题无可行解，停止计算。
第二阶段：划去人工变量列，将第一阶段最终表中的目标行恢复为原问题的价值系数向量，以第一阶段求得的基可行解作为第二阶段初始表，继续用单纯形法迭代直至最优。

五、对偶单纯形法 (Dual Simplex Method) 对偶可行性 · 消除负右端项 · 灵敏度与割平面基础
方法核心原理与规范要求（依据教材第3章第4节）：

对偶单纯形法适用于具有正规解（即对偶可行，所有检验数 $\sigma_j \le 0$），但常数项列向量 $b$ 中至少存在一个负分量（原问题不可行）的线性规划问题。
计算步骤：
1. 确定换出变量（出基）：按“负值最大”原则，取 $\min_i \{ b_i \mid b_i < 0 \} = b_l$，对应的基变量 $x_l$ 为换出变量。
2. 确定换入变量（进基）：检查换出变量所在行元素 $a_{lj}$，若所有 $a_{lj} \ge 0$，则该问题无可行解，停止计算；若存在 $a_{lj} < 0$，按 $\theta$ 规则计算比值： $$\theta = \min_j \left\{ \frac{\sigma_j}{a_{lj}} \;\middle|\; a_{lj} < 0 \right\} = \frac{\sigma_k}{a_{lk}}$$ 对应的非基变量 $x_k$ 为换入变量。
3. 以 $a_{lk} < 0$ 为主元素进行行初等变换，使主元素化为 1，该列其余元素化为 0。重复迭代直至所有 $b_i \ge 0$ 时，即得原问题最优解。

六、割平面法 (Gomory Cutting Plane Method) 纯小数分解 · 割平面方程 · 对偶单纯形整数迭代
方法核心原理与规范要求（依据教材第6章第2节）：

割平面法通过不断添加线性约束（即“割平面”），切除非整数解同时保留全部整数可行解，从而迫使松弛单纯形法的最优解逼近整数格点。
推导步骤：
1. 先忽略整数约束，用单纯形法求出松弛线性规划的最优解。若所得最优解均为整数，则已达最优；若存在非整数分量，转下一步。
2. 导出割平面方程：从最优单纯形表中，选取一个具有非整数解 $b_i$ 的基变量行方程： $$x_i + \sum_k a_{ik} x_k = b_i$$ 将所有系数 $a_{ik}$ 与常数项 $b_i$ 分解为整数 $N$ 与非负纯真分数 $f \in [0, 1)$： $$a_{ik} = N_{ik} + f_{ik}, \quad b_i = N_{bi} + f_{bi} \quad (0 \le f < 1)$$ 整理方程得： $$x_i + \sum_k N_{ik} x_k - N_{bi} = f_{bi} - \sum_k f_{ik} x_k$$ 因为当变量均为非负整数时，等式左边必为整数，而右边由于 $f_{bi} < 1$ 且 $\sum f_{ik} x_k \ge 0$，故右边必为 $\le 0$ 的非正整数。由此导出Gomory割平面方程： $$f_{bi} - \sum_k f_{ik} x_k \le 0 \iff -\sum_k f_{ik} x_k \le -f_{bi}$$
3. 引入松弛变量化为等式，添加入原最优单纯形表中，利用对偶单纯形法消除负的右端项，继续迭代直到求得全整数最优解。

第二步：导出割平面方程

从最优表中抄下 $x_2$ 所在的非整数行方程（一般选取 $b$ 值小数部分较大的方程）： $$x_2 + \frac{1}{5}x_3 + \frac{2}{5}x_4 = \frac{14}{5}$$ 拆分为整数部分与非负纯小数部分： $$\frac{14}{5} = 2 + \frac{4}{5}, \quad \frac{1}{5} = 0 + \frac{1}{5}, \quad \frac{2}{5} = 0 + \frac{2}{5}$$ 变形得： $$x_2 - 2 = \frac{4}{5} - \left(\frac{1}{5}x_3 + \frac{2}{5}x_4\right)$$ 由于左边是整数，右边必为非正整数，由此导出 Gomory 割平面方程： $$\frac{4}{5} - \left(\frac{1}{5}x_3 + \frac{2}{5}x_4\right) \le 0 \iff -\frac{1}{5}x_3 - \frac{2}{5}x_4 \le -\frac{4}{5}$$ 引入非负松弛变量 $x_5 \ge 0$，化为标准等式： $$-\frac{1}{5}x_3 - \frac{2}{5}x_4 + x_5 = -\frac{4}{5}$$
