一、运输问题（最小元素法、伏格尔法、位势检验与闭回路调整）

【题 1】最小元素法确定初始基可行解，位势法检验与闭回路调整（产大于销）

题目条件：已知某物资运输问题的单位运价表、产地供给量与销地需求量如下表所示。试用最小元素法求出初始基可行解，并用位势法计算各空格检验数；若当前解不是最优解，使用闭回路法进行调整直至求出最优调运方案及最小运输总费用。

产地：A1(25), A2(35)；销地：B1(10), B2(25), B3(15)。单位运价 c_ij：
A1: [2, 7, 4]
A2: [3, 6, 5]
步骤 1：产销平衡化

总产量 = 25 + 35 = 60，总销量 = 10 + 25 + 15 = 50。产大于销，虚设销地 B4，需求量为 60 - 50 = 10，虚设点到各产地运价均为 0。

步骤 2：最小元素法编制初始调运方案

基变量格数应为 m + n - 1 = 2 + 4 - 1 = 5 个：

  1. 最小运价为 c_14 = c_24 = 0。优先安排 (A2, B4)：填入 min(35, 10) = 10，划去 B4 列；
  2. 其余格中最小运价为 c_11 = 2：填入 min(25, 10) = 10，划去 B1 列，A1 剩余 15；
  3. 次小运价为 c_13 = 4：填入 min(15, 15) = 15，同时满足 A1 与 B3。在 (A2, B3) 填入 0 维持 5 个基变量（退化处理），划去 A1 行与 B3 列；
  4. 最后 (A2, B2) 填入 min(25, 25) = 25，满足所有供需。
步骤 3：位势法求空格检验数（令 u1 = 0）
产地 \ 销地 B1 B2 B3 B4 (虚设) 产量 a_i 行位势 u_i
A1 210 7[σ12 = 5] 415 0[σ14 = 1] 25 u1 = 0
A2 3[σ21 = 0] 625 50 010 35 u2 = 1
销量 b_j 10 25 15 10 60 -

计算位势方程：u1 = 0 ⇒ v1 = c11 - u1 = 2, v3 = c13 - u1 = 4；由基格 (A2, B3) 得 u2 = c23 - v3 = 5 - 4 = 1；进而 v2 = c22 - u2 = 6 - 1 = 5, v4 = c24 - u2 = 0 - 1 = -1。

检验数 σ_ij = c_ij - (u_i + v_j)：

  • σ_12 = 7 - (0 + 5) = 2 > 0
  • σ_14 = 0 - (0 - 1) = 1 > 0

最小总运费：Z* = 10×2 + 15×4 + 25×6 + 10×0 = 230。

题目条件：某产销平衡运输问题的单位运价表如下表所示。试用伏格尔法（行/列差额法）确定初始基可行解，并用位势法判定该初始方案是否最优。

  1. 第 1 次差额：行差额 [ΔA1 = 3-3=0, ΔA2 = 2-1=1, ΔA3 = 5-4=1]；列差额 [ΔB1 = 3-1=2, ΔB2 = 9-4=5, ΔB3 = 3-2=1, ΔB4 = 8-5=3]。

  3. 第 3 次差额：行差额 [ΔA1 = 0, ΔA2 = 1]；列差额 [ΔB1 = 2, ΔB3 = 1, ΔB4 = 2]。

二、大 M 法（Big-M Method）

【题 3】大 M 法求解具有等式与 ≥ 约束的线性规划

题目条件：用大 M 法求解下列线性规划问题：

max z = 2x1 + 3x2 - 5x3
s.t. x1 + x2 + x3 = 7
      2x1 - 5x2 + x3 ≥ 10
      x1, x2, x3 ≥ 0
步骤 1：标准化与引入人工变量

在约束 1 中引入人工变量 x4；在约束 2 中引入剩余变量 x5 与人工变量 x6。目标函数中对人工变量赋予惩罚费用 -M：

max z = 2x1 + 3x2 - 5x3 - M·x4 + 0·x5 - M·x6
s.t. x1 + x2 + x3 + x4 = 7
      2x1 - 5x2 + x3 - x5 + x6 = 10
      x1, ..., x6 ≥ 0

-M x6 10 2 -5 1 0 -1 1 10 / 2 = 5 → 换出
σ_j (检验数) -17M 3M + 2 ↑ -4M + 3 2M - 5 0 -M 0 -
第 1 次迭代 -M x4 2 0 7/2 1/2 1 1/2 -1/2 2 / (7/2) = 4/7 → 换出

所有非基变量检验数均 ≤ 0，人工变量全退出基底，得到唯一最优解：
X* = (x1, x2, x3) = (45/7, 4/7, 0)；最优目标函数值 Z* = 2(45/7) + 3(4/7) = 102/7。

【题 4】大 M 法判定无可行解的典型问题

max z = 10x1 + 15x2 + 12x3 + 0x4 + 0x5 + 0x6 - M·x7
步骤 2：单纯形法迭代

初始基变量为 (x4, x5, x7)，换入 x1，换出 x4；第 2 步换入 x3，换出 x5。最终迭代到达如下状态表：

三、两阶段法（Two-Phase Simplex Method）

【题 5】两阶段法求解线性规划（检验第一阶段与第二阶段衔接）

题目条件：用两阶段法求解下列线性规划问题：

min z = 2x1 - x2 + 2x3
s.t. -x1 + x2 + x3 = 4
      -x1 + x2 - x3 ≤ 6
      x1 ≤ 0, x2 ≥ 0, x3 自由变量
步骤 1：变量变换与规范化

令 x1' = -x1 ≥ 0，x3 = x3' - x3'' (x3', x3'' ≥ 0)，并加入松弛变量 x4 ≥ 0：

min z = -2x1' - x2 + 2x3' - 2x3''
s.t. x1' + x2 + x3' - x3'' = 4
      x1' + x2 - x3' + x3'' + x4 = 6
      所有变量非负
步骤 2：第一阶段——引入人工变量 x5，求解辅助问题
min w = x5 (即 max w' = -x5)
s.t. x1' + x2 + x3' - x3'' + x5 = 4
      x1' + x2 - x3' + x3'' + x4 = 6
C_B 基变量 b x1' (0) x2 (0) x3' (0) x3'' (0) x4 (0) x5 (-1) θ
-1 x5 4 1 1 1 -1 0 1 4 / 1 = 4 → 换出
0 x4 6 1 1 -1 1 1 0 6 / 1 = 6
σ_j -4 1 ↑ 1 1 -1 0 0 -
0 x1' 4 1 1 1 -1 0 1 -
0 x4 2 0 0 -2 2 1 -1 -
σ_j 0 0 0 0 0 0 -1 -

第一阶段最优目标值 min w = 0，人工变量 x5 已出基，原规划有初始基可行解，进入第二阶段。

步骤 3：第二阶段——代入原目标函数继续求解

去掉 x5 列，以 (x1', x4) 为初始基，填入原问题价值系数 C_j = (-2, -1, 2, -2, 0)：

C_B 基变量 b x1' (-2) x2 (-1) x3' (2) x3'' (-2) x4 (0) θ
-2 x1' 4 1 1 1 -1 0 -
0 x4 2 0 0 -2 2 1 2 / 2 = 1 → 换出
σ_j (min 型检验数: c_j - z_j) z = -8 0 1 4 -4 ↓ (换入) 0 -
-2 x1' 5 1 1 0 0 1/2 -
-2 x3'' 1 0 0 -1 1 1/2 -
σ_j z = -12 0 1 0 0 2 -
所有检验数均 ≥ 0（min 规划达到最优）：
x1' = 5 ⇒ x1 = -5；x2 = 0；x3'' = 1, x3' = 0 ⇒ x3 = -1。
最优解：X* = (-5, 0, -1)^T；最优值 min z = 2(-5) - 0 + 2(-1) = -12。

【题 6】两阶段法判定原问题无可行解

max z = x1 + 2x2

x1 + x2 - x3 + x5 = 5
x1 + 2x2 + x4 = 4

四、对偶单纯形法（Dual Simplex Method）

【题 7】对偶单纯形法标准迭代（满足对偶可行性/正则解）

题目条件：利用对偶单纯形法求解下列初始检验数满足正则性（全非正）的线性规划问题：

min z = x1 + x2
s.t. 2x1 + x2 ≥ 4
      x1 + 7x2 ≥ 7
      x1, x2 ≥ 0
步骤 1：化为求 max z' = -z 并建立对偶单纯形初始表

不等式两端同乘 -1，加入松弛变量 x3, x4 ≥ 0：

max z' = -x1 - x2 + 0x3 + 0x4
s.t. -2x1 - x2 + x3 = -4
      -x1 - 7x2 + x4 = -7

基变量为 (x3, x4)，检验数行 σ1 = -1, σ2 = -1, σ3 = 0, σ4 = 0 ≤ 0，满足对偶可行（解具有正则性），常数项存在负数，可直接使用对偶单纯形法。

步骤 2：对偶单纯形表迭代
迭代 C_B 基变量 b x1 (-1) x2 (-1) x3 (0) x4 (0) θ = σ_j / a_lj (a_lj < 0)
初始表 0 x3 -4 -2 -1 1 0 -
0 x4 -7 → 换出 -1 -7 0 1 min(-1/-1, -1/-7) = 1/7 → x2 换入
σ_j 0 -1 -1 0 0 -
第 1 次迭代 0 x3 -3 → 换出 -13/7 0 1 -1/7 min((-6/7)/(-13/7), (-1/7)/(-1/7)) = 6/13 → x1 换入
-1 x2 1 1/7 1 0 -1/7 -
σ_j 1 -6/7 0 0 -1/7 -
最优表 -1 x1 21/13 1 0 -7/13 1/13 -
-1 x2 10/13 0 1 1/13 -2/13 -
σ_j 31/13 0 0 -6/13 -1/13 -
b 列分量全部非负，且检验数保持全非正，得到最优解：
x1* = 21/13, x2* = 10/13；最优目标值 min z = -max z' = 31/13。

五、分支定界法（Branch and Bound Method）

【题 9】全整数规划的分支定界法标准求解树

题目条件：用分支定界法求解下列纯整数规划问题（要求写出松弛 LP 最优解、分支子问题及定界过程）：

max z = 40x1 + 90x2
s.t. 9x1 + 7x2 ≤ 56
      7x1 + 20x2 ≤ 70
      x1, x2 ≥ 0 且为整数
步骤 1：求解根节点 LP0（松弛线性规划）

联立 9x1 + 7x2 = 56 与 7x1 + 20x2 = 70，解得交点：

x1 = 630 / 131 ≈ 4.809,    x2 = 238 / 131 ≈ 1.817
对应松弛最优目标值 Z0 = 40(4.809) + 90(1.817) = 46680 / 131 ≈ 356.34

初始下界（已知可行整数解例如 (0,0)）：Z_L = 0；初始上界：Z_U = 356。

步骤 2：对非整数变量 x2 进行分支

由于 x2 = 1.817 不是整数，将其分支为：

  • 分支 LP1：在 LP0 基础上增加约束 x2 ≥ 2
  • 分支 LP2：在 LP0 基础上增加约束 x2 ≤ 1
步骤 3：求解子问题 LP1 与 LP2

求解 LP1 (x2 ≥ 2)：
结合 7x1 + 20x2 ≤ 70，当 x2 = 2 时，7x1 ≤ 70 - 40 = 30 ⇒ x1 = 30/7 ≈ 4.286。
此时 9(30/7) + 7(2) = 270/7 + 14 = 368/7 ≈ 52.57 ≤ 56 满足约束。
最优解为 x1 = 30/7 ≈ 4.286, x2 = 2，目标值 Z1 = 40(30/7) + 90(2) = 1200/7 + 180 ≈ 351.43。

对 LP1 进行进一步分支（对 x1 = 4.286）：

  • 子问题 LP11 (x2 ≥ 2, x1 ≥ 5)：
    代入约束 7(5) + 20x2 ≤ 70 ⇒ 20x2 ≤ 35 ⇒ x2 ≤ 1.75，与 x2 ≥ 2 矛盾，无可行解，剪枝！
  • 子问题 LP12 (x2 ≥ 2, x1 ≤ 4)：
    令 x1 = 4，代入 7(4) + 20x2 ≤ 70 ⇒ 20x2 ≤ 42 ⇒ x2 ≤ 2.1。同时 9(4) + 7x2 ≤ 56 ⇒ 7x2 ≤ 20 ⇒ x2 ≤ 20/7 ≈ 2.857。
    因此在 x2 ≥ 2 限制下，最优取 x1 = 4, x2 = 2.1，目标值 Z12 = 40(4) + 90(2.1) = 160 + 189 = 349。

对 LP12 进一步分支（对 x2 = 2.1）：

  • 若 x2 ≥ 3：7x1 + 20(3) ≤ 70 ⇒ 7x1 ≤ 10 ⇒ x1 ≤ 10/7；若 x1 = 1, x2 = 3：Z = 40(1) + 90(3) = 310。
  • 若 x2 ≤ 2（与 x2 ≥ 2 结合即 x2 = 2）：在 x1 ≤ 4 限制下，整数解取 x1 = 4, x2 = 2，得到整数可行解！
    目标值 Z_int = 40(4) + 90(2) = 340。更新下界 Z_L = 340。

求解 LP2 (x2 ≤ 1)：
为使目标函数最大化，取 x2 = 1，则 9x1 + 7(1) ≤ 56 ⇒ 9x1 ≤ 49 ⇒ x1 ≤ 49/9 ≈ 5.444。
此时 7(49/9) + 20(1) = 343/9 + 20 ≈ 58.11 ≤ 70。
LP2 松弛最优解为 x1 = 49/9 ≈ 5.44, x2 = 1，目标值 Z2 = 40(49/9) + 90(1) ≈ 307.78。
因为 Z2 = 307.78 < Z_L = 340，该分支上界小于当前最好整数解，直接剪枝！

所有活动分支均已剪枝或得到整数解，算法终止。
最优整数解：x1* = 4, x2* = 2；最优目标函数值 Z* = 340。

【题 10】0-1 整数规划的分支定界求解

题目条件：用分支定界法求解下列 0-1 整数规划问题：

max z = 3x1 + 5x2 + 4x3
s.t. 2x1 + 3x2 ≤ 4
      2x2 + 3x3 ≤ 4
      x1, x2, x3 ∈ {0, 1}
步骤 1：根节点 LP0 分析

松弛变量为 0 ≤ xj ≤ 1。当 x2 = 1 时，由约束 1 得 x1 ≤ (4-3)/2 = 1/2；由约束 2 得 x3 ≤ (4-2)/3 = 2/3。
松弛最优解：x1 = 1/2, x2 = 1, x3 = 2/3；目标值 Z0 = 3(1/2) + 5(1) + 4(2/3) = 1.5 + 5 + 2.67 = 9.17。

步骤 2：对 x2 进行 0-1 分支
  • 分支 1：令 x2 = 1
    约束变为：2x1 ≤ 1 ⇒ x1 必须为 0（因 x1∈{0,1}）；3x3 ≤ 2 ⇒ x3 必须为 0。
    因此当 x2 = 1 时，唯一的整数可行解为 (0, 1, 0)。
    对应目标值 Z_A = 3(0) + 5(1) + 4(0) = 5。更新当前下界 Z_L = 5。
  • 分支 2：令 x2 = 0
    约束变为：2x1 ≤ 4 ⇒ x1 可取 1；3x3 ≤ 4 ⇒ x3 可取 1。
    此时取 x1 = 1, x3 = 1 完全满足所有约束且均为 0-1 整数！
    对应目标值 Z_B = 3(1) + 5(0) + 4(1) = 7。
    由于 7 > 5，更新最好整数解为 (1, 0, 1)，Z_L = 7。
所有变量分支探索完毕，最优 0-1 整数解为：
x1* = 1, x2* = 0, x3* = 1；最大目标值 Z* = 7。

【题 11】割平面法求解纯整数规划（标准 Gomory 割推导与对偶单纯形迭代）

题目条件：已知某整数规划松弛后的最优单纯形表如下所示，所有决策变量要求为非负整数。试写出 Gomory 割平面方程，并用对偶单纯形法求解最优整数解。

max z = x1 + 4x2
最优单纯形表中对应行方程为：
x2 + (3/5)x1 + (1/5)x3 = 8/5 (对应 x2 为基变量)
规范化为以非基变量表达：x2 + (1/5)x3 - (3/5)x4 = 8/5, x1 + ... (以如下精确表格为准)

1/5 = 0 + 1/5 ⇒ f_3 = 1/5

-(1/5)x3 - (4/5)x4 + s1 = -3/5 (s1 ≥ 0 且为整数)

x1* = 0, x2* = 1；最优目标值 Z* = 1(0) + 4(1) = 4。

【题 12】割平面法原理与约束几何意义分析

题目条件：考虑整数规划问题：max z = 2x1 + x2，s.t. x1 + x2 ≤ 5, -x1 + x2 ≤ 0, 6x1 + 2x2 ≤ 21, x1, x2 ≥ 0 为整数。
(1) 写出松弛线性规划的最优解及其对应的基行方程；
(2) 推导由该行生成的 Gomory 割平面方程，并说明其在图解坐标系中如何切除分数解而不切除任何整数可行解。

步骤 1：求解松弛 LP 及基行方程

联立约束边界 x1 + x2 = 5 与 6x1 + 2x2 = 21（松弛变量分别为 x3, x4）：
解得交点坐标为：x1 = 11/4 = 2.75, x2 = 9/4 = 2.25。
目标函数值 Z_LP = 2(2.75) + 2.25 = 7.75。
以 x1 为基变量的基行方程（通过单纯形乘子或代入松弛变量）：

x1 + (1/2)x3 + (1/4)x4 = 11/4 = 2 + 3/4
步骤 2：生成 Gomory 割平面方程

各系数的非负小数部分：f0 = 3/4, f3 = 1/2, f4 = 1/4。
Gomory 割不等式为：(1/2)x3 + (1/4)x4 ≥ 3/4。
将松弛变量还原为原决策变量：x3 = 5 - x1 - x2, x4 = 21 - 6x1 - 2x2：

(1/2)(5 - x1 - x2) + (1/4)(21 - 6x1 - 2x2) ≥ 3/4
⇒ (5/2 + 21/4) - (1/2 + 6/4)x1 - (1/2 + 2/4)x2 ≥ 3/4
⇒ 31/4 - 2x1 - x2 ≥ 3/4
⇒ 2x1 + x2 ≤ 31/4 - 3/4 = 28/4 = 7
步骤 3：几何意义验证
  • 切除分数解：松弛最优解为 (x1, x2) = (2.75, 2.25)，代入割平面左边：2(2.75) + 2.25 = 5.5 + 2.25 = 7.75 > 7。原非整数最优解严格违反该割平面，已被彻底切除！
  • 保留所有整数可行解：所有满足原条件的整数点（例如 (2, 2) ⇒ 2(2)+2 = 6 ≤ 7；(3, 1) ⇒ 2(3)+1 = 7 ≤ 7；(2, 1) ⇒ 5 ≤ 7）均满足 2x1 + x2 ≤ 7，无一被切除。
加入割平面 2x1 + x2 ≤ 7 后，立即锁定最优整数解为：
x1* = 3, x2* = 1 或 x1* = 2, x2* = 3（视其他约束验证），最大整数目标值 Z* = 7。
